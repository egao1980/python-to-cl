* Pillow / OpenCV
:PROPERTIES:
:UNNUMBERED: t
:END:
https://pillow.readthedocs.io/en/stable/

https://docs.opencv.org/4.x/

Pillow is the friendly PIL fork. It adds image processing capabilities to your Python interpreter.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ Read and write ~30 formats: PNG, JPEG, GIF, TIFF, WebP, BMP ...
+ Modes (~L~, ~RGB~, ~RGBA~, ~P~), conversion, EXIF
+ Resize, crop, rotate, thumbnails, filters
+ ~ImageDraw~ / ~ImageFont~: shapes and text
+ OpenCV (~opencv-python~): computer vision, video, camera capture

** Common Lisp alternatives
:PROPERTIES:
:UNNUMBERED: t
:END:

The cl-stack [[https://github.com/egao1980/cl-stack/blob/main/docs/capabilities/image.md][image brief]] calls opticl heavy and pngload unsafe (~safety 0~, no APNG), and imports only zpng, cl-jpeg and skippy. cl-repo has carried opticl since 2026-11-24 ([[https://github.com/egao1980/cl-stack-systems/issues/76][cl-stack-systems#76]]), for examples like the one below.

Fixed on 2026-11-23: resize, crop, rotate, flip, thumbnail and composite ([[https://github.com/egao1980/image-protocol/issues/2][image-protocol#2]], image-protocol 0.2.0). 2026-11-24: native resize through image-backend-stb 0.3.0 (image-protocol 0.3.0); the pure-Lisp resize with ~:reducing-gap~ is 1.8–4.4× faster for reductions of 4× and more, same pixels ([[https://github.com/egao1980/image-protocol/issues/9][image-protocol#9]], 0.3.1; demo [[https://github.com/egao1980/cl-stack-demos/tree/main/harness/image-ops][harness/image-ops]]). Gaps: no filters or drawing; no pixel budget for ~fit-image~ ([[https://github.com/egao1980/image-protocol/issues/6][image-protocol#6]]); ~image-backend-lisp~ (pure CL) is in the README but not published ([[https://github.com/egao1980/cl-stack/issues/275][cl-stack#275]]).

(asdf:load-system "zpng")

#+end_src

Write a 4×2 gradient with zpng:
#+begin_src lisp
(let* ((png (make-instance 'zpng:png :width 4 :height 2 :color-type :truecolor))
       (data (zpng:data-array png)))
  (dotimes (y 2)
    (dotimes (x 4)
      (setf (aref data y x 0) (* x 60)
            (aref data y x 1) 0
            (aref data y x 2) (* y 200))))
  (zpng:write-png png "grad.png" :if-exists :supersede)
  (with-open-file (s "grad.png" :element-type '(unsigned-byte 8))
    (file-length s)))
#+end_src

#+RESULTS:
: 90

Probe reads the header only:
#+begin_src lisp
(let ((info (stack-image:probe-image #p"grad.png")))
  (list (stack-image:image-info-format info)
        (stack-image:image-info-width info)
        (stack-image:image-info-height info)
        (stack-image:image-info-pixel-format info)))
#+end_src

#+RESULTS:
: (:PNG 4 2 :RGB)

Decode, re-encode as JPEG, convert to grayscale:
#+begin_src lisp
(let* ((img (stack-image:decode-image #p"grad.png"))
       (jpg (stack-image:encode-image img :jpeg :quality 80)))
  (list (stack-image:image-format img)
        (subseq (stack-image:image-pixels img) 0 6)
        (stack-image:sniff-format jpg)
        (subseq (stack-image:image-pixels (stack-image:convert-image img :gray)) 0 4)))
#+end_src

#+RESULTS:
: (:RGB #(0 0 0 60 0 0) :JPEG #(0 18 36 54))

Limits protect against decompression bombs:
#+begin_src lisp
(let ((stack-image:*image-limits* (stack-image:make-image-limits :max-pixels 4)))
  (handler-case (stack-image:decode-image #p"grad.png")
    (error (e) (type-of e))))
#+end_src

#+RESULTS:
: IMAGE-PROTOCOL:IMAGE-LIMIT-EXCEEDED

~im.resize~ (nearest and bilinear to 2×1), ~im.crop~, ~im.rotate(90)~ (sides swap), ~im.thumbnail~ (keeps 2:1):
#+begin_src lisp
(let ((img (stack-image:decode-image #p"grad.png")))
  (flet ((size (i) (list (stack-image:image-width i) (stack-image:image-height i))))
    (list (stack-image:image-pixels (stack-image:resize-image img 2 1 :filter :nearest))
          (stack-image:image-pixels (stack-image:resize-image img 2 1 :filter :bilinear))
          (stack-image:image-pixels (stack-image:crop-image img 1 1 2 1))
          (size (stack-image:rotate-image img 90))
          (size (stack-image:thumbnail img 2 2)))))
#+end_src

#+RESULTS:
: (#(60 0 200 180 0 200) #(43 0 100 137 0 100) #(60 0 200 120 0 200) (2 4) (2 1))

Rotation is by multiples of 90°:
#+begin_src lisp
(handler-case (stack-image:rotate-image (stack-image:decode-image #p"grad.png") 45)
  (stack-image:image-invalid-argument (e) (type-of e)))
#+end_src

#+RESULTS:
: IMAGE-PROTOCOL:IMAGE-INVALID-ARGUMENT

*** skippy
Animated GIF, two frames:
#+begin_src lisp
(let* ((colors (skippy:make-color-table))
       (black (skippy:ensure-color #x000000 colors))
       (white (skippy:ensure-color #xFFFFFF colors))
       (stream (skippy:make-data-stream :width 8 :height 8 :color-table colors :loopingp t)))
  (dolist (c (list black white))
    (skippy:add-image (skippy:make-image :width 8 :height 8 :delay-time 50
                                         :image-data (skippy:make-image-data 8 8 :initial-element c))
                      stream))
  (skippy:output-data-stream stream #p"blink.gif")
  (let ((frames (stack-image:decode-frames #p"blink.gif")))
    (list (length (stack-image:image-sequence-frames frames))
          (stack-image:image-frame-delay-ms (first (stack-image:image-sequence-frames frames))))))
#+end_src

#+RESULTS:
: (2 500)

Resize to 100 × 200 and write a JPEG; the array is height × width × channels:
#+begin_src lisp
(let ((img (opticl:read-png-file "grad.png")))
