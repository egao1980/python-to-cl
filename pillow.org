* Pillow / OpenCV
:PROPERTIES:
:UNNUMBERED: t
:END:
https://pillow.readthedocs.io/en/stable/

https://docs.opencv.org/4.x/

Pillow is the friendly PIL fork. It adds image processing capabilities to your Python interpreter.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ Read and write ~30 formats: PNG, JPEG, GIF, TIFF, WebP, BMP ...
+ Modes (~L~, ~RGB~, ~RGBA~, ~P~), conversion, EXIF
+ Resize, crop, rotate, thumbnails, filters
+ ~ImageDraw~ / ~ImageFont~: shapes and text
+ OpenCV (~opencv-python~): computer vision, video, camera capture

:UNNUMBERED: t

Write a 4×2 gradient with zpng:
#+begin_src lisp
(let* ((png (make-instance 'zpng:png :width 4 :height 2 :color-type :truecolor))
       (data (zpng:data-array png)))
  (dotimes (y 2)
    (dotimes (x 4)
      (setf (aref data y x 0) (* x 60)
            (aref data y x 1) 0
            (aref data y x 2) (* y 200))))
  (zpng:write-png png "grad.png" :if-exists :supersede)
  (with-open-file (s "grad.png" :element-type '(unsigned-byte 8))
    (file-length s)))
#+end_src

#+RESULTS:
: 90

Probe reads the header only:
#+begin_src lisp
(let ((info (stack-image:probe-image #p"grad.png")))
  (list (stack-image:image-info-format info)
        (stack-image:image-info-width info)
        (stack-image:image-info-height info)
        (stack-image:image-info-pixel-format info)))
#+end_src

#+RESULTS:
: (:PNG 4 2 :RGB)

Decode, re-encode as JPEG, convert to grayscale:
#+begin_src lisp
(let* ((img (stack-image:decode-image #p"grad.png"))
       (jpg (stack-image:encode-image img :jpeg :quality 80)))
  (list (stack-image:image-format img)
        (subseq (stack-image:image-pixels img) 0 6)
        (stack-image:sniff-format jpg)
        (subseq (stack-image:image-pixels (stack-image:convert-image img :gray)) 0 4)))
#+end_src

#+RESULTS:
: (:RGB #(0 0 0 60 0 0) :JPEG #(0 18 36 54))

Limits protect against decompression bombs:
#+begin_src lisp
(let ((stack-image:*image-limits* (stack-image:make-image-limits :max-pixels 4)))
  (handler-case (stack-image:decode-image #p"grad.png")
    (error (e) (type-of e))))
#+end_src

#+RESULTS:
: IMAGE-PROTOCOL:IMAGE-LIMIT-EXCEEDED

Resize is not in the protocol yet. Nearest neighbour by hand:
#+begin_src lisp
(defun resize-nearest (img new-w new-h)
  (let* ((w (stack-image:image-width img)) (h (stack-image:image-height img))
         (c (length (string (stack-image:image-format img)))) ; :rgb → 3, :rgba → 4
         (src (stack-image:image-pixels img))
         (dst (make-array (* new-w new-h c) :element-type '(unsigned-byte 8))))
    (dotimes (y new-h)
      (dotimes (x new-w)
        (replace dst src :start1 (* c (+ x (* y new-w)))
                         :start2 (* c (+ (floor (* x w) new-w) (* (floor (* y h) new-h) w)))
                         :end2 (+ c (* c (+ (floor (* x w) new-w) (* (floor (* y h) new-h) w)))))))
    (stack-image:make-image :width new-w :height new-h :format (stack-image:image-format img)
                            :depth 8 :pixels dst)))

(let ((small (resize-nearest (stack-image:decode-image #p"grad.png") 2 1)))
  (list (stack-image:image-width small) (stack-image:image-pixels small)))
#+end_src

#+RESULTS:
: (2 #(0 0 0 120 0 0))

*** skippy
Animated GIF, two frames:
#+begin_src lisp
(let* ((colors (skippy:make-color-table))
       (black (skippy:ensure-color #x000000 colors))
       (white (skippy:ensure-color #xFFFFFF colors))
       (stream (skippy:make-data-stream :width 8 :height 8 :color-table colors :loopingp t)))
  (dolist (c (list black white))
    (skippy:add-image (skippy:make-image :width 8 :height 8 :delay-time 50
                                         :image-data (skippy:make-image-data 8 8 :initial-element c))
                      stream))
  (skippy:output-data-stream stream #p"blink.gif")
  (let ((frames (stack-image:decode-frames #p"blink.gif")))
    (list (length (stack-image:image-sequence-frames frames))
          (stack-image:image-frame-delay-ms (first (stack-image:image-sequence-frames frames))))))
#+end_src

#+RESULTS:
: (2 500)
