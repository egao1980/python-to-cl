* Google Cloud / Azure SDKs
:PROPERTIES:
:UNNUMBERED: t
:END:
https://cloud.google.com/python/docs/reference

https://learn.microsoft.com/en-us/azure/developer/python/sdk/azure-sdk-overview

The Google Cloud and Azure client libraries for Python: one package per service over shared core libraries (~google-api-core~, ~azure-core~).

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ Storage, databases, queues, functions, AI services: one client per service
+ Credential chains: environment, files, metadata servers, managed identities
+ Retries, pagination, long-running operations
+ AWS: see [[file:boto3.org][boto3]]

** Python to CL examples
:PROPERTIES:
:UNNUMBERED: t
:END:
A public bucket needs no credentials, so the Cloud Storage JSON API can be called directly:
#+begin_src python
client = storage.Client.create_anonymous_client()
[(b.name, b.size) for b in client.list_blobs("gcp-public-data-landsat", max_results=2)]
#+end_src

*** cl-stack
#+begin_src lisp :exports source :results silent
(asdf:load-system "cl-stack-ssl")
(asdf:load-system "cl-stack-http")
#+end_src

#+begin_src lisp
(let* ((r (cl-stack-http:get "https://storage.googleapis.com/storage/v1/b/gcp-public-data-landsat/o"
                             :params '(("maxResults" . "2") ("fields" . "items(name,size)"))))
       (items (gethash "items" (cl-stack-http:response-json r))))
  (map 'list (lambda (o) (list (subseq (gethash "name" o) 0 24) (gethash "size" o))) items))
#+end_src
