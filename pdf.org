* pypdf / ReportLab / PyMuPDF
:PROPERTIES:
:UNNUMBERED: t
:END:
https://pypdf.readthedocs.io/en/stable/

https://docs.reportlab.com/

pypdf is a free and open-source pure-python PDF library capable of splitting, merging, cropping, and transforming the pages of PDF files.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ pypdf: read, merge, split, rotate, encrypt; text and metadata
+ ReportLab: generate PDFs: canvas drawing, Platypus layout (paragraphs, tables), charts
+ PyMuPDF: fast text and image extraction, page rendering, annotations
+ pdfplumber / pdfminer.six: text with layout, tables

Fixed on 2026-11-23: the default backend reads unencrypted files with no password ([[https://github.com/egao1980/doc-extract-backend-pdf/issues/9][doc-extract-backend-pdf#9]], 0.1.5). Gaps: no PDF writer in cl-stack (output goes through Chrome; cl-pdf writes, below); no merge, split or encryption; PDFium is not thread-safe, so extracting from several threads at once crashes SBCL ([[https://github.com/egao1980/doc-extract-backend-pdf/issues/17][doc-extract-backend-pdf#17]]).

*** cl-pdf, cl-typesetting
Write a page with cl-pdf, then read it back with the PDFium backend:
#+begin_src lisp :exports source :results silent
(asdf:load-system "cl-pdf")
(asdf:load-system "cl-typesetting")
#+end_src

#+begin_src lisp
(pdf:with-document ()
  (pdf:with-page ()
    (pdf:in-text-mode
      (pdf:set-font (pdf:get-font "Helvetica") 24.0)
      (pdf:move-text 72 770)
      (pdf:draw-text "Quarterly report")))
  (pdf:write-document #p"cl-pdf.pdf"))
(stack-doc-extract:extract-text *pdf* #p"cl-pdf.pdf" :format :pdf)
#+end_src

#+RESULTS:
: Quarterly report

Paragraphs laid out by cl-typesetting:
#+begin_src lisp
(tt:with-document ()
  (let ((content (tt:compile-text ()
                   (tt:paragraph (:font "Helvetica-Bold" :font-size 20) "Quarterly report")
                   (tt:paragraph (:font "Helvetica" :font-size 12) "Sales grew in both regions."))))
    (tt:draw-pages content)
    (when pdf:*page* (tt:finalize-page pdf:*page*))
    (tt:write-document #p"typeset.pdf")))
(stack-doc-extract:extract-text *pdf* #p"typeset.pdf" :format :pdf)
#+end_src
