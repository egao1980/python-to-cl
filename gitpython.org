* GitPython
:PROPERTIES:
:UNNUMBERED: t
:END:
https://gitpython.readthedocs.io/en/stable/

GitPython is a python library used to interact with git repositories, high-level like git-porcelain, or low-level like git-plumbing.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ Open, clone and init repositories
+ Commits, history, diffs, branches, tags, remotes
+ Index and working tree: stage, commit, checkout
+ Object database access; the ~git~ command as a fallback

*** cl-stack
https://github.com/egao1980/cl-stack/blob/main/docs/capabilities/revision-backend-git.md

#+begin_src lisp :exports source :results silent
(asdf:load-system "revision-backend-git")
(asdf:load-system "process-backend-uiop")

(defvar *repo* (merge-pathnames "demo-repo/" (uiop:getcwd)))
(uiop:delete-directory-tree *repo* :validate t :if-does-not-exist :ignore)
(ensure-directories-exist *repo*)

(defun git (&rest args)
  (stack-process:run (list* "git" "-C" (namestring *repo*)
                            "-c" "user.name=Demo" "-c" "user.email=demo@example.com" args)))

(git "init" "-q" "-b" "main")
(with-open-file (s (merge-pathnames "README.md" *repo*) :direction :output)
  (write-line "# Demo" s))
(git "add" "README.md")
(git "commit" "-q" "-m" "Add README")
(with-open-file (s (merge-pathnames "README.md" *repo*) :direction :output :if-exists :append)
  (write-line "More." s))
(git "commit" "-q" "-am" "Expand README")
#+end_src

History and a diff summary:
#+begin_src lisp
(stack-rev-git:with-git-store (store *repo*)
  (list (mapcar #'stack-rev:revision-message
                (stack-rev:walk-revisions store (stack-rev:rev-ref "main")))
        (stack-diff:render-diff (stack-rev:state-diff store "main~1" "main" :level :summary)
                                :summary nil)))
#+end_src
