This module provides various memoizing collections and decorators, including variants of the Python Standard Library's @lru_cache function decorator.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ ~functools.cache~ / ~lru_cache~: memoize a function, bounded by size
+ cachetools: LRU, LFU, TTL and random-replacement caches; ~@cached~ with custom keys and locks
+ diskcache: persistent caches on disk

** Common Lisp alternatives
:PROPERTIES:
:UNNUMBERED: t
:END:

*** Plain CL
#+begin_src lisp
(defmacro defmemo (name lambda-list &body body)
  "DEFUN with results cached by EQUAL arguments, thread-safe."
  (let ((table (gensym "TABLE")) (lock (gensym "LOCK")))
    `(let ((,table (make-hash-table :test #'equal))
           (,lock (sb-thread:make-mutex)))
       (defun ,name (&rest args)
         (multiple-value-bind (value found)
             (sb-thread:with-mutex (,lock) (gethash args ,table))
           (if found
               value
               (let ((value (destructuring-bind ,lambda-list args ,@body)))
                 (sb-thread:with-mutex (,lock) (setf (gethash args ,table) value)))))))))

(defmemo fib (n)
  (if (< n 2) n (+ (fib (- n 1)) (fib (- n 2)))))

(fib 200)
#+end_src

*** cl-stack
cachetools' ~TTLCache~ with a clock you control:
#+begin_src lisp :exports source :results silent
(asdf:load-system "cache-protocol")
#+end_src

#+begin_src lisp
(let* ((now 0)
       (c (stack-cache:make-in-memory-ttl-cache :clock (lambda () now))))
  (stack-cache:cache-put c "rates" '(:usd 1.08) :ttl 600)
  (list (stack-cache:cache-get c "rates")
        (progn (setf now 601) (stack-cache:cache-get c "rates"))))
#+end_src

#+RESULTS:
: ((:USD 1.08) NIL)

On the default clock a TTL can be a fraction of a second:
#+begin_src lisp
(let ((c (stack-cache:make-in-memory-ttl-cache)))
  (stack-cache:cache-put c "token" "abc" :ttl 0.3)
  (list (stack-cache:cache-get c "token")
        (progn (sleep 0.35) (stack-cache:cache-get c "token"))))
#+end_src

#+RESULTS:
: ("abc" NIL)

~cache-incr~ is atomic, 8 threads × 10000:
#+begin_src lisp
(asdf:load-system "bordeaux-threads")
(let ((c (stack-cache:make-in-memory-ttl-cache)))
  (mapc #'bt2:join-thread
        (loop repeat 8
              collect (bt2:make-thread
                       (lambda () (dotimes (_ 10000) (stack-cache:cache-incr c "hits"))))))
  (stack-cache:cache-get c "hits"))
#+end_src

#+RESULTS:
: 80000

~:timeout~ in seconds; the second call within it is a hit, the one after it fetches again (results, then the fetch count):
#+begin_src lisp
(defvar *fetches* 0)
(function-cache:defcached (rates :timeout 1) ()
  (incf *fetches*)
  '(:usd 1.08))
(list (rates) (rates) *fetches*
      (progn (sleep 1.5) (rates)) *fetches*)
#+end_src

#+RESULTS:
: ((:USD 1.08) (:USD 1.08) 1 (:USD 1.08) 2)

Bounded: ~:cache-class 'function-cache:lru-cache~ (fixed capacity, least recently used evicted).
