* Scrapy / Selenium / Playwright
:PROPERTIES:
:UNNUMBERED: t
:END:
https://docs.scrapy.org/en/latest/

https://playwright.dev/python/

Scrapy is a fast high-level web crawling and web scraping framework, used to crawl websites and extract structured data from their pages.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ Scrapy: spiders, link following, throttling, ~robots.txt~, item pipelines, JSON / CSV export
+ Selenium: real browsers through WebDriver (Chrome, Firefox, Safari)
+ Playwright: Chromium, Firefox and WebKit; auto-waiting, screenshots, PDF, network interception
+ Parsing with CSS / XPath selectors (see [[file:lxml.org][lxml / Beautiful Soup]])

Gaps: browser-protocol does not start a browser or match CDP replies by id, and ~navigate~ does not wait for the page ([[https://github.com/egao1980/browser-protocol/issues/2][browser-protocol#2]]); without json-protocol loaded its fallback JSON reader fails on ~false~ ([[https://github.com/egao1980/browser-protocol/issues/1][browser-protocol#1]]). No crawler: scheduling, ~robots.txt~, throttling.

*** A real browser
Headless Chrome over the DevTools protocol, the Playwright route. Needs Google Chrome installed. Until browser-protocol has a launcher, the glue is ours:
#+begin_src python
with sync_playwright() as p:
    page = p.chromium.launch().new_page()
    page.goto("https://example.com/")
    page.title(), page.screenshot(), page.pdf()
#+end_src

#+begin_src lisp :exports source :results silent
(asdf:load-system "browser-protocol")
(asdf:load-system "json-backend-jzon")
(asdf:load-system "ws-backend-websocket-driver")
(asdf:load-system "process-backend-uiop")
(asdf:load-system "image-protocol")

(defvar *chrome*
  (stack-process:launch
   (list "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
         "--headless=new" "--remote-debugging-port=19222" "--no-first-run"
         (format nil "--user-data-dir=~a" (uiop:native-namestring (merge-pathnames "chrome-profile/" (uiop:getcwd))))
         "about:blank")
   :output nil :error-output nil))

(defun page-ws-url ()
  "The DevTools WebSocket URL of the first page target."
  (loop repeat 50
        do (handler-case
               (let ((page (find "page" (com.inuoe.jzon:parse
                                         (cl-stack-http:response-text
                                          (cl-stack-http:get "http://127.0.0.1:19222/json/list")))
                                 :key (lambda (target) (gethash "type" target)) :test #'equal)))
                 (when page (return (gethash "webSocketDebuggerUrl" page))))
             (error () (sleep 0.2)))))

(defvar *inbox* '())
(defvar *inbox-lock* (bt2:make-lock))
(defvar *devtools* (ws:connect (page-ws-url) :transport :http/1.1
                               :backend (ws-backend-websocket-driver:make-websocket-driver-backend)))
(ws:on *devtools* :message
       (lambda (m) (bt2:with-lock-held (*inbox-lock*) (setf *inbox* (append *inbox* (list m))))))

(defvar *page*
  (stack-browser:make-cdp-browser-backend
   :send-fn (lambda (command) (ws:send *devtools* (com.inuoe.jzon:stringify command)))
   :recv-fn (lambda () (loop (bt2:with-lock-held (*inbox-lock*) (when *inbox* (return (pop *inbox*))))
                             (sleep 0.01)))))
#+end_src

#+begin_src lisp
(stack-browser:navigate *page* "https://example.com/")
(sleep 2)                               ; navigate does not wait for load yet
(list (stack-browser:eval-js *page* "document.title")
      (stack-browser:eval-js *page* "[...document.querySelectorAll('a')].map(a => a.href)"))
#+end_src
