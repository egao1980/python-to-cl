* Scrapy / Selenium / Playwright
:PROPERTIES:
:UNNUMBERED: t
:END:
https://docs.scrapy.org/en/latest/

https://playwright.dev/python/

Scrapy is a fast high-level web crawling and web scraping framework, used to crawl websites and extract structured data from their pages.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ Scrapy: spiders, link following, throttling, ~robots.txt~, item pipelines, JSON / CSV export
+ Selenium: real browsers through WebDriver (Chrome, Firefox, Safari)
+ Playwright: Chromium, Firefox and WebKit; auto-waiting, screenshots, PDF, network interception
+ Parsing with CSS / XPath selectors (see [[file:lxml.org][lxml / Beautiful Soup]])

*** Static pages
https://quotes.toscrape.com is a sandbox for scrapers.

#+begin_src python
html = requests.get("https://quotes.toscrape.com/").text
[q.get_text() for q in BeautifulSoup(html, "html.parser").select(".quote .author")][:3]
#+end_src

#+begin_src lisp :exports source :results silent
(asdf:load-system "cl-stack-ssl")
(asdf:load-system "cl-stack-http")
(asdf:load-system "html-backend-plump")
#+end_src

#+begin_src lisp
(let ((doc (stack-html:parse (cl-stack-http:response-text (cl-stack-http:get "https://quotes.toscrape.com/")))))
  (subseq (mapcar #'stack-html:element-text (stack-html:select doc ".quote .author")) 0 3))
#+end_src

#+RESULTS:
: ("Albert Einstein" "J.K. Rowling" "Albert Einstein")

lQuery, Beautiful Soup's ~select~ and ~get_text~:
#+begin_src lisp
(asdf:load-system "lquery")
(let ((html (cl-stack-http:response-text (cl-stack-http:get "https://quotes.toscrape.com/"))))
  (coerce (subseq (lquery:$ (initialize html) ".quote .author" (text)) 0 3) 'list))
#+end_src

#+RESULTS:
: ("Albert Einstein" "J.K. Rowling" "Albert Einstein")

*** A real browser
Headless Chrome over the DevTools protocol, the Playwright route. Needs Chrome, Chromium or Edge installed; ~launch-browser~ finds it (or ~$CHROME_PATH~), starts it with a temporary profile and attaches to a page:
#+begin_src python
with sync_playwright() as p:
    page = p.chromium.launch().new_page()
    page.goto("https://example.com/")
    page.title(), page.screenshot(), page.pdf()
#+end_src

#+begin_src lisp :exports source :results silent
(asdf:load-system "browser-protocol/launch")
(asdf:load-system "image-protocol")

(defvar *page* (stack-browser:launch-browser))
#+end_src

~navigate~ waits for the load event (~:wait-until~ ~:load~, ~:domcontentloaded~ or ~:commit~; ~:timeout~):
#+begin_src lisp
(stack-browser:navigate *page* "https://example.com/")
(list (stack-browser:eval-js *page* "document.title")
      (stack-browser:eval-js *page* "document.readyState")
      (stack-browser:eval-js *page* "[...document.querySelectorAll('a')].map(a => a.href)"))
#+end_src

#+RESULTS:
: ("Example Domain" "complete" #("https://iana.org/help/example-domains"))

Screenshot (PNG) and PDF bytes:
#+begin_src lisp
(let ((png (stack-browser:screenshot *page*))
      (pdf (stack-browser:print-pdf *page*)))
  (list (stack-image:sniff-format png) (map 'string #'code-char (subseq pdf 0 5))))
#+end_src

#+RESULTS:
: (:PNG "%PDF-")

~close-browser~ stops Chrome and removes the profile:
#+begin_src lisp
(stack-browser:close-browser *page*)
#+end_src

#+RESULTS:
: T
