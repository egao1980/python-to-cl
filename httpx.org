* HTTPX / aiohttp
:PROPERTIES:
:UNNUMBERED: t
:END:
https://www.python-httpx.org/

https://docs.aiohttp.org/

HTTPX is a fully featured HTTP client for Python 3, which provides sync and async APIs, and support for both HTTP/1.1 and HTTP/2.
aiohttp is an asynchronous HTTP client/server framework for asyncio.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ A broadly requests-compatible API
+ Standard synchronous interface, but with async support if you need it
+ HTTP/1.1 and HTTP/2 support
+ Strict timeouts everywhere
+ Calling into WSGI / ASGI applications directly
+ aiohttp: client and server, client and server WebSockets, middlewares

Concurrent requests: ~asyncio.run~ is ~run-promise~, ~gather~ is ~gather~:
#+begin_src lisp
(let ((start (get-internal-real-time)))
  (list (mapcar #'http:response-status
                (evp:run-promise
                 (lambda ()
                   (evp:gather (http:get-async "https://httpbin.org/delay/1")
                               (http:get-async "https://httpbin.org/delay/1")
                               (http:get-async "https://httpbin.org/delay/1")))
                 :backend *libuv*))
        (round (- (get-internal-real-time) start) internal-time-units-per-second)))
#+end_src

#+RESULTS:
: ((200 200 200) 1)
