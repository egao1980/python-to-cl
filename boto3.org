* boto3
:PROPERTIES:
:UNNUMBERED: t
:END:
https://boto3.amazonaws.com/v1/documentation/api/latest/index.html

Boto3 is the Amazon Web Services (AWS) Software Development Kit (SDK) for Python.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ Clients for every AWS service, generated from botocore models
+ Credential chain: environment, config files, SSO, instance metadata
+ Paginators and waiters
+ S3: managed multipart transfers, presigned URLs
+ Works against S3-compatible stores (MinIO, R2) via ~endpoint_url~

** Common Lisp alternatives
:PROPERTIES:
:UNNUMBERED: t
:END:
S3 has mature libraries. Pirá generates clients for 400+ services from the official AWS models, but calls itself alpha. The 2024 survey summary: "Several folks asked for better a AWS SDK story".

*** cl-stack
| Library                                                                          | Version | Verdict                                                                                                                                                                                                                                  |
|----------------------------------------------------------------------------------+---------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [[https://github.com/egao1980/object-store-protocol][object-store-protocol]]     | 0.1.0   | S3-shaped API: ~put-object~ / ~get-object~ / ~head-object~ / ~list-objects~, conditional puts, presigned URLs, multipart. In-memory store for tests.                                                                                     |
| [[https://github.com/egao1980/object-store-backend-s3][object-store-backend-s3]] | 0.2.1   | AWS SigV4 S3 / MinIO backend. Sends through http-protocol by default (or an ~:http-fn~ you pass); botocore's credential chain: environment, =~/.aws/credentials=, =~/.aws/config=, ~:profile~ / ~AWS_PROFILE~; region from ~AWS_REGION~. |

Fixed on 2026-11-24: the default HTTP function and the credential chain ([[https://github.com/egao1980/object-store-backend-s3/issues/4][object-store-backend-s3#4]], 0.2.0), on cl-stack-config 0.3.1's ~parse-ini~, which reads the shared files as botocore does ([[https://github.com/egao1980/cl-stack-config/issues/10][cl-stack-config#10]]); ~head-object~ returns the size ([[https://github.com/egao1980/object-store-backend-s3/issues/10][#10]], 0.2.1). Demo [[https://github.com/egao1980/cl-stack-demos/tree/main/harness/s3-minio][harness/s3-minio]] runs against a live MinIO. Gaps: no container / instance-metadata credentials, SSO or assume-role ([[https://github.com/egao1980/object-store-backend-s3/issues/6][#6]]); profile selection differs from botocore in corner cases ([[https://github.com/egao1980/object-store-backend-s3/issues/9][#9]]).

No other AWS services. Google Cloud and Azure: see [[file:cloud.org][Google Cloud / Azure SDKs]].

*** cl-stack

The protocol against the in-memory store:
#+begin_src lisp
(let ((store (os:make-in-memory-object-store)))
  (os:put-object store "a/b.txt" "hello")
  (os:put-object store "a/c.txt" "world")
  (list (babel:octets-to-string (os:get-object store "a/b.txt"))
        (handler-case (os:get-object store "missing")
          (os:object-not-found (e) (type-of e)))))
#+end_src

#+RESULTS:
: ("hello" OS:OBJECT-NOT-FOUND)

The S3 backend signs requests locally. A presigned URL needs no network (keys from the AWS documentation):
#+begin_src python
s3.generate_presigned_url("get_object", Params={"Bucket": "examplebucket", "Key": "test.txt"}, ExpiresIn=86400)
#+end_src

#+begin_src lisp :post shorten(*this*)
(let ((s3 (object-store-backend-s3:make-s3-backend
           :endpoint "https://s3.amazonaws.com"
           :region "us-east-1"
           :bucket "examplebucket"
           :access-key "AKIAIOSFODNN7EXAMPLE"
           :secret-key "wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY")))
  (os:presign-url s3 "test.txt" :expires 86400))
#+end_src

#+RESULTS:
: https://s3.amazonaws.com/examplebucket/test.txt?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=AKIAIOSFODNN7EXAMPL...

With no keys given, the backend walks the credential chain, as ~boto3.client("s3")~ does. Here the same keys come from a shared credentials file:
#+begin_src lisp :results silent
(with-open-file (s "credentials" :direction :output :if-exists :supersede)
  (format s "[default]~%aws_access_key_id = AKIAIOSFODNN7EXAMPLE~%aws_secret_access_key = wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY~%"))
(setf (uiop:getenv "AWS_SHARED_CREDENTIALS_FILE") (namestring (truename "credentials")))
#+end_src

#+begin_src lisp :post shorten(*this*)
(let ((s3 (object-store-backend-s3:make-s3-backend
           :endpoint "https://s3.amazonaws.com" :region "us-east-1" :bucket "examplebucket")))
  (os:presign-url s3 "test.txt" :expires 86400))
#+end_src

#+RESULTS:
: https://s3.amazonaws.com/examplebucket/test.txt?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=AKIAIOSFODNN7EXAMPL...

Real requests go through http-protocol with no ~:http-fn~; load cl-stack-http and its ~:auto~ backend is used. Against MinIO (not run here; demo [[https://github.com/egao1980/cl-stack-demos/tree/main/harness/s3-minio][harness/s3-minio]]):
#+begin_src lisp :eval no
(asdf:load-system "cl-stack-http")
(let ((s3 (object-store-backend-s3:make-s3-backend
           :endpoint "http://127.0.0.1:9000" :bucket "my-bucket")))
  (os:put-object s3 "a/b.txt" "hello")
  (os:get-object s3 "a/b.txt"))
#+end_src
