* scikit-learn
:PROPERTIES:
:UNNUMBERED: t
:END:
https://scikit-learn.org/stable/

scikit-learn is a Python module for machine learning built on top of SciPy.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ Classification and regression: linear models, SVM, trees, random forests, gradient boosting
+ Clustering (k-means, DBSCAN), dimensionality reduction (PCA)
+ Preprocessing, pipelines, feature extraction from text
+ Cross-validation, grid search, metrics; one ~fit~ / ~predict~ / ~transform~ API

*** Plain CL
k-means in a few lines:
#+begin_src lisp
(defun kmeans (points k &key (iterations 10))
  (let ((centers (subseq points 0 k)))
    (labels ((dist (a b) (reduce #'+ (map 'list (lambda (x y) (expt (- x y) 2)) a b)))
             (nearest (p) (position (reduce #'min centers :key (lambda (c) (dist p c))) centers
                                    :key (lambda (c) (dist p c))))
             (mean (ps) (apply #'map 'list (lambda (&rest xs) (/ (reduce #'+ xs) (length xs))) ps)))
      (dotimes (_ iterations)
        (setf centers (loop for i below k
                            collect (mean (remove-if-not (lambda (p) (= i (nearest p))) points)))))
      (values (mapcar #'nearest points) centers))))

(multiple-value-list (kmeans '((1 1) (3/2 2) (8 8) (9 17/2) (1 0) (8 9)) 2))
#+end_src
