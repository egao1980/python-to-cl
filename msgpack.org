* msgpack / pickle
:PROPERTIES:
:UNNUMBERED: t
:END:
https://msgpack-python.readthedocs.io/en/latest/

https://docs.python.org/3/library/pickle.html

MessagePack is an efficient binary serialization format. It lets you exchange data among multiple languages like JSON. But it's faster and smaller.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ msgpack: JSON-like data in compact binary, ~bin~ and ~ext~ types, streaming ~Unpacker~
+ CBOR (~cbor2~): the IETF counterpart, tags
+ pickle: any Python object graph, shared and circular references, ~__reduce__~ hooks
+ ~shelve~, ~dill~, ~cloudpickle~ build on pickle

** Common Lisp alternatives
:PROPERTIES:
:UNNUMBERED: t
:END:
~prin1~ and ~read~ (under ~with-standard-io-syntax~, ~*read-eval*~ off) already serialize lists, strings, numbers, symbols and arrays as text. The libraries add binary formats and CLOS objects.

** Python to CL examples
:PROPERTIES:
:UNNUMBERED: t
:END:
*** cl-stack
#+begin_src lisp :exports source :results silent
(asdf:load-system "messagepack-protocol")
(asdf:load-system "cbor-protocol")
(asdf:load-system "sexp-protocol")
(asdf:load-system "io-protocol")
(asdf:load-system "cl-store")
(asdf:load-system "marshal")
#+end_src

#+begin_src python
packed = msgpack.packb({"id": 1, "tags": ["a", "b"], "raw": b"\x00\x01"})
msgpack.unpackb(packed)
#+end_src

#+begin_src lisp
(let* ((value (alexandria:alist-hash-table
               `(("id" . 1) ("tags" . #("a" "b"))
                 ("raw" . ,(make-array 2 :element-type '(unsigned-byte 8) :initial-contents '(0 1))))
               :test #'equal))
       (packed (stack-messagepack:encode value))
       (back (stack-messagepack:decode packed)))
  (list (length packed)
        (gethash "tags" back)
        (type-of (gethash "raw" back))))
#+end_src

#+RESULTS:
: (23 #("a" "b") (SIMPLE-ARRAY (UNSIGNED-BYTE 8) (2)))

CBOR through the serdes registry:
#+begin_src lisp
(let ((octets (serdes-protocol:encode #(1 2 3 :null) :format :cbor)))
  (list octets (serdes-protocol:decode octets :format :cbor)))
#+end_src

#+RESULTS:
: (#(132 1 2 3 246) #(1 2 3 :NULL))

S-expressions:
#+begin_src lisp
(let ((text (serdes-protocol:encode '(:point :x 1 :y 2) :format :sexp)))
  (list text (serdes-protocol:decode text :format :sexp)))
#+end_src

#+RESULTS:
: ("(:POINT :X 1 :Y 2)" (:POINT :X 1 :Y 2))

*** cl-store
#+begin_src python
pickle.dump(obj, open("obj.pickle", "wb"))
pickle.load(open("obj.pickle", "rb"))
#+end_src

CLOS objects and circular structure:
#+begin_src lisp
(defclass point () ((x :initarg :x) (y :initarg :y)))

(let ((cycle (list 1 2 3)))
  (setf (cdr (last cycle)) cycle)
  (cl-store:store (list (make-instance 'point :x 1 :y 2) cycle) #p"obj.store")
  (destructuring-bind (p c) (cl-store:restore #p"obj.store")
    (list (slot-value p 'y) (eq c (cdddr c)))))
#+end_src

#+RESULTS:
: (2 T)

*** cl-marshal
Printable output, slots chosen per class:
#+begin_src lisp
(defmethod ms:class-persistent-slots ((p point)) '(x y))

(let ((m (ms:marshal (make-instance 'point :x 3 :y 4))))
  (list m (slot-value (ms:unmarshal m) 'x)))
#+end_src

#+RESULTS:
: ((:PCODE 1 (:OBJECT 1 POINT :COMMON-LISP-USER 3 4)) 3)
