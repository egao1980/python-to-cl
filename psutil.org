* psutil
:PROPERTIES:
:UNNUMBERED: t
:END:
https://psutil.readthedocs.io/en/latest/

psutil (process and system utilities) is a cross-platform library for retrieving information on running processes and system utilization (CPU, memory, disks, network, sensors) in Python.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ CPU counts, times and percentages; load average
+ Memory, swap, disk partitions and usage, I/O counters; network interfaces and connections
+ Processes: list, details (command line, memory, open files, threads), signals, kill
+ Battery, sensors, users, boot time

*** cl-stack
No system monitoring. [[https://github.com/egao1980/process-protocol][process-protocol]] (0.4.1) knows the processes it starts (~process-pid~, process groups, ~kill :tree~); [[https://github.com/egao1980/supervisor-protocol][supervisor-protocol]] (0.5.0) keeps state for supervised units.

*** SBCL and POSIX tools
#+begin_src lisp :exports source :results silent
(asdf:load-system "process-backend-uiop")

(defun command-output (&rest argv)
  (string-trim '(#\Newline #\Space)
               (babel:octets-to-string (nth-value 1 (stack-process:run argv)))))
#+end_src

CPU count, this image's heap use and its resident memory:
#+begin_src lisp
(list (parse-integer (command-output "getconf" "_NPROCESSORS_ONLN"))
      (floor (sb-kernel:dynamic-usage) (* 1024 1024))
      (floor (parse-integer (command-output "ps" "-o" "rss=" "-p" (princ-to-string (sb-posix:getpid))))
             1024))
#+end_src

#+RESULTS:
: (10 57 103)

A child process, ~psutil.Process(pid)~:
#+begin_src lisp
(let ((child (stack-process:launch '("sleep" "5"))))
  (prog1 (command-output "ps" "-o" "comm=" "-p" (princ-to-string (stack-process:process-pid child)))
    (stack-process:kill child)))
#+end_src

#+RESULTS:
: sleep

*** machine-state
The package has no short nickname, so give it a local one:
#+begin_src lisp :exports source :results silent
(asdf:load-system "machine-state")

(defpackage #:psutil-demo
  (:use #:cl)
  (:local-nicknames (#:ms #:org.shirakumo.machine-state)))
(in-package #:psutil-demo)
#+end_src

#+begin_src lisp
(ms:machine-cores)
#+end_src

#+RESULTS:
: 10
