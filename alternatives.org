* Foreword 
:PROPERTIES:

:END:
Common Lisp is a nice and expressive language and this project is an effort to promote or improve CL libraries by comparing to the corresponding Python alternatives.

Each page: the Python package's features, the third-party Common Lisp libraries, the [[https://github.com/egao1980/cl-stack][cl-stack]] ones, then examples. Reviewed November 2026.

* No good alternative yet
:PROPERTIES:
:UNNUMBERED: t
:END:
- PyTorch, TensorFlow, transformers: [[https://github.com/melisgl/mgl][MGL]] (active, small) and [[https://github.com/hikettei/cl-waffe2][cl-waffe2]] (experimental, last commit 2024-12). Call Python through [[https://github.com/digikar99/py4cl2][py4cl2]].
- scikit-learn, SciPy: [[https://github.com/mmaul/clml][CLML]] gets compatibility fixes only; GSLL fails to install with current CFFI ([[https://aliquote.org/post/cl-tooling-in-2025/][Common Lisp tooling in 2025]]).
- matplotlib: [[https://github.com/Lisp-Stat/plot][Lisp-Stat plot]] (Vega-Lite in a browser) or gnuplot wrappers. No native plotting library.
- Selenium / Playwright: [[https://github.com/copyleft/cl-webdriver-client][cl-webdriver-client]], last commit 2024-09.
- Other AWS and Google Cloud SDKs: only S3, see [[file+emacs:boto3.org][boto3]].
- psutil: nothing portable.

* Loading libraries
:PROPERTIES:
:UNNUMBERED: t
:END:
Examples load libraries with [[https://github.com/egao1980/cl-repository][cl-repo]] from ~ghcr.io/egao1980/cl-systems~, not Quicklisp:

#+begin_src sh
curl -fsSL https://raw.githubusercontent.com/egao1980/cl-repository/main/install.sh | bash
mkdir demo && cd demo
echo '(defsystem "demo" :depends-on ("dexador" "cl-stack-http"))' > demo.asd
cl-repo sync
cl-repo ros +Q run
#+end_src

Then ~(asdf:load-system "dexador")~ in the REPL. ~+Q~ keeps Roswell's Quicklisp out, so a system missing from the project fails instead of loading from Quicklisp.

Libraries that are not in cl-repo are shown with their documented examples, marked "not run". Results come from SBCL 2.4.11 on macOS arm64, 2026-11-23.
