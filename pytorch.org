* PyTorch / TensorFlow / transformers
:PROPERTIES:
:UNNUMBERED: t
:END:
https://pytorch.org/docs/stable/

https://huggingface.co/docs/transformers/

PyTorch is an optimized tensor library for deep learning using GPUs and CPUs.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ Tensors on CPU and GPU, automatic differentiation
+ ~nn~ modules, optimizers, data loaders, training loops
+ Export (TorchScript, ONNX), distributed training
+ transformers: pretrained models and tokenizers, ~pipeline~ for inference

** Common Lisp alternatives
:PROPERTIES:
:UNNUMBERED: t
:END:
No mature deep-learning framework. Training stays in Python; Lisp can run models (llama.cpp, ONNX) or call Python.

** Python to CL examples
:PROPERTIES:
:UNNUMBERED: t
:END:
A 260K-parameter model trained on TinyStories, 1.2 MB:
#+begin_src sh
curl -fsSL -o models/stories260K.gguf \
  https://huggingface.co/ggml-org/models/resolve/main/tinyllamas/stories260K.gguf
#+end_src

#+begin_src python
llm = Llama("models/stories260K.gguf")
llm("Once upon a time", max_tokens=24, temperature=0)["choices"][0]["text"]
#+end_src

*** cl-stack
#+begin_src lisp :exports source :results silent
(asdf:load-system "llm-backend-llama-cpp")

(defvar *model* (stack-llm-llama-cpp:make-llama-cpp-backend
                 :model-path (namestring (truename "models/stories260K.gguf"))))
#+end_src

#+begin_src lisp
(stack-llm:llm-response-text
 (stack-llm:generate *model* "Once upon a time" :settings '(:max-tokens 24 :temperature 0)))
#+end_src
