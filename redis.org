* redis-py
:PROPERTIES:
:UNNUMBERED: t
:END:
https://redis.readthedocs.io/en/stable/

The Python interface to the Redis key-value store.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ Every command: strings, hashes, lists, sets, sorted sets, streams
+ Connection pools, pipelines, transactions (~MULTI~ / ~WATCH~)
+ Pub/sub, Lua scripts, RESP3
+ Cluster and Sentinel clients, asyncio client

Gaps: cache commands only (no hashes, lists, pub/sub, pipelines), and no ~connect~: you open the socket ([[https://github.com/egao1980/cache-backend-redis/issues/3][cache-backend-redis#3]]).

** Python to CL examples
:PROPERTIES:
:UNNUMBERED: t
:END:
The examples talk to Valkey 8 in Docker: ~docker run --rm -p 127.0.0.1:16379:6379 valkey/valkey:8~.

#+begin_src python
r = redis.Redis(port=16379)
r.set("greeting", "hello", ex=60)
r.get("greeting"), r.incr("hits")
#+end_src

*** cl-stack
#+begin_src lisp :exports source :results silent
(asdf:load-system "cache-backend-redis")
(asdf:load-system "usocket")

(defvar *socket* (usocket:socket-connect "127.0.0.1" 16379 :element-type '(unsigned-byte 8)))
(defvar *redis* (cache-backend-redis:make-redis-cache-backend :stream (usocket:socket-stream *socket*)))
#+end_src

#+begin_src lisp
(list (stack-cache:cache-put *redis* "greeting" "hello" :ttl 60)
      (stack-cache:cache-get *redis* "greeting")
      (stack-cache:cache-incr *redis* "hits"))
#+end_src

#+RESULTS:
: ("hello" "hello" 4)

Compare-and-set, the ~WATCH~ / ~MULTI~ use case:
#+begin_src lisp
(list (stack-cache:cache-cas *redis* "greeting" "hello" "hi")
      (handler-case (stack-cache:cache-cas *redis* "greeting" "hello" "hey")
        (stack-cache:cache-cas-mismatch () :mismatch))
      (stack-cache:cache-delete *redis* "greeting")
      (stack-cache:cache-get *redis* "greeting"))
#+end_src

#+RESULTS:
: ("hi" :MISMATCH T NIL)

The same code runs on the in-memory cache, e.g. in tests, with a clock you control:
#+begin_src lisp
(let* ((now 1000)
       (c (stack-cache:make-in-memory-ttl-cache :clock (lambda () now))))
  (stack-cache:cache-put c "k" "v" :ttl 60)
  (list (stack-cache:cache-get c "k")
        (progn (incf now 61) (stack-cache:cache-get c "k"))))
#+end_src

#+RESULTS:
: ("v" NIL)

Its TTL has whole-second resolution and is not thread-safe yet ([[https://github.com/egao1980/cache-protocol/issues/1][cache-protocol#1]]).

The RESP3 wire, for commands the protocol does not cover:
#+begin_src lisp
(babel:octets-to-string (cache-backend-redis:encode-resp3-command '("HSET" "user:1" "name" "Ann")))
#+end_src

#+RESULTS:
#+begin_example
,*4
$4
HSET
$6
user:1
$4

$3

#+end_example
