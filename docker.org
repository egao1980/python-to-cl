* Docker SDK
:PROPERTIES:
:UNNUMBERED: t
:END:
https://docker-py.readthedocs.io/en/stable/

A Python library for the Docker Engine API. It lets you do anything the docker command does, but from within Python apps.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ Containers: run, list, logs, exec, stop, remove
+ Images: pull, build, tag, push
+ Networks, volumes, Swarm services
+ The Engine API over the local socket or TLS

#+begin_src python
client = docker.from_env()
client.containers.run("alpine:3.20", ["sh", "-c", "cat /etc/alpine-release"], remove=True, network_mode="none")
#+end_src

*** cl-stack
#+begin_src lisp :exports source :results silent
(asdf:load-system "compute-backend-podman")
(asdf:load-system "process-backend-uiop")

(defvar *docker* (compute-backend-podman:make-podman-compute-backend
                  :program "docker" :default-image "alpine:3.20"))
#+end_src

A throwaway container, no network unless the spec allows it:
#+begin_src lisp
(let ((r (stack-compute:run-sandboxed
          *docker*
          (stack-compute:make-sandbox-spec
           :command '("sh" "-c" "cat /etc/alpine-release; wget -q -T 2 -O- https://example.com || echo no network")))))
  (list (stack-compute:sandbox-result-exit-code r) (stack-compute:sandbox-result-stdout r)))
#+end_src
