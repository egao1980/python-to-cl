* mypy
:PROPERTIES:
:UNNUMBERED: t
:END:
https://mypy.readthedocs.io/en/stable/

Mypy is a static type checker for Python.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ Checks type hints before the program runs; gradual typing
+ Generics, protocols, unions, ~Optional~, ~TypedDict~, ~Literal~
+ Inference for unannotated code; strict modes
+ pyright / ty: faster checkers with editor integration

** Common Lisp alternatives
:PROPERTIES:
:UNNUMBERED: t
:END:
The checker is the compiler. SBCL infers types, checks ~declare~ / ~declaim ftype~ and ~check-type~, warns at compile time when a value can never fit, and inserts run-time checks at safe settings. For a static type system with inference, [[https://github.com/coalton-lang/coalton][Coalton]] embeds one in CL.

*** SBCL
A declared type that cannot fit is a compile-time warning. The helper collects the compiler's warnings:
#+begin_src lisp
(defun compile-warnings (form)
  "Compile FORM; return the compiler's warnings as one-line strings."
  (let ((messages '()))
    (handler-bind ((warning
                     (lambda (w)
                       (let* ((words (remove "" (uiop:split-string (princ-to-string w)
                                                                   :separator '(#\Space #\Newline))
                                             :test #'string=))
                              (text (format nil "~{~a~^ ~}" words)))
                         (push (subseq text 0 (search " See also" text)) messages))
                       (muffle-warning w))))
      (compile nil form))
    (nreverse messages)))

(compile-warnings '(lambda (x)
                    (declare (fixnum x))
                    (concatenate 'string x "!")))
#+end_src

#+RESULTS:
: ("Derived type of COMMON-LISP-USER::X is (VALUES FIXNUM &OPTIONAL), conflicting with its asserted type SEQUENCE.")

Function types with Serapeum's ~->~, checked at call sites:
#+begin_src lisp :exports source :results silent
(asdf:load-system "serapeum")
#+end_src

#+begin_src lisp
(serapeum:-> shout (string) string)
(defun shout (s) (concatenate 'string (string-upcase s) "!"))

(compile-warnings '(lambda () (shout 42)))
#+end_src

#+RESULTS:
: ("Constant 42 conflicts with its asserted type STRING.")

At run time, under the default safety, the declaration is checked:
#+begin_src lisp
(handler-case (funcall (compile nil '(lambda (x) (declare (fixnum x)) (1+ x))) "3")
  (type-error (e) (list (type-error-datum e) (type-error-expected-type e))))
#+end_src

#+RESULTS:
: ("3" FIXNUM)
