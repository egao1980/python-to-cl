Python-Markdown is a Python implementation of John Gruber's Markdown.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ Markdown to HTML
+ Extensions: tables, fenced code, footnotes, table of contents, syntax highlighting
+ markdown-it-py: CommonMark compliant, token stream, plugins (rich uses it)
+ mistune: fast, AST renderer, plugins

** Python to CL examples
:PROPERTIES:
:UNNUMBERED: t
:END:
*** cl-stack
https://github.com/egao1980/cl-stack/blob/main/docs/capabilities/markdown.md

#+begin_src lisp :exports source :results silent
(asdf:load-system "html-markdown")
(asdf:load-system "org-markup")

(defparameter *doc* "# Title

Some *emphasis*, `code` and a [link](https://example.com).

| a | b |
|---|--:|
| 1 | 2 |
")
#+end_src

#+begin_src python
markdown.markdown(doc, extensions=["tables"])
#+end_src

#+begin_src lisp
(html-markdown:markdown-html *doc*)
#+end_src

#+RESULTS:
#+begin_example
<h1>Title</h1>
<p>Some <em>emphasis</em>, <code>code</code> and a <a href="https://example.com">link</a>.</p>
<table>
<thead>
<tr><th>a</th><th align="right">b</th></tr>
</thead>
<tbody>
<tr><td>1</td><td align="right">2</td></tr>
</tbody>
</table>
#+end_example

The AST, the markdown-it token stream role:
#+begin_src lisp
(stack-markdown:parse-markdown *doc*)
#+end_src

#+RESULTS:
#+begin_example
((:HEADING 1 ("Title"))
 (:PARAGRAPH
  ("Some " (:EMPH ("emphasis")) ", " (:CODE "code") " and a "
   (:LINK "https://example.com" ("link")) "."))
 (:TABLE (NIL :RIGHT) (("a") ("b")) ((("1") ("2")))))
#+end_example

Unsafe links are dropped by default:
#+begin_src lisp
(html-markdown:markdown-html "[x](javascript:alert(1)) ![y](data:text/html,hi)")
#+end_src

#+RESULTS:
: <p>x y</p>

Heading ids for a table of contents, headings shifted one level:
#+begin_src lisp
(html-markdown:markdown-html "# Intro
## Use cases" :heading-ids t :heading-offset 1)
#+end_src

#+RESULTS:
#+begin_example
<h2 id="intro">Intro</h2>
<h3 id="use-cases">Use cases</h3>
#+end_example

Org goes through the same renderer:
#+begin_src lisp
(multiple-value-bind (blocks keywords)
    (stack-org:parse-org
     (format nil "#+TITLE: Notes~%* Hello~%Some /emphasis/ and [[https://example.com][a link]]."))
  (list keywords (html-markdown:markdown-html blocks)))
#+end_src

#+RESULTS:
#+begin_example
((("title" . "Notes")) "<h1>Hello</h1>
<p>Some <em>emphasis</em> and <a href=\"https://example.com\">a link</a>.</p>
")
#+end_example
