openpyxl is a Python library to read/write Excel 2010 xlsx/xlsm/xltx/xltm files.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ openpyxl: read and write ~.xlsx~: cells, formulas, styles, merged cells, charts
+ XlsxWriter: write-only, fast, rich formatting and charts; xlrd: old ~.xls~
+ python-docx: read and write ~.docx~: paragraphs, styles, tables, images
+ python-pptx: PowerPoint slides

Gaps: no ~.xlsx~ / ~.docx~ writing. The XLSX reader skips the worksheets (empty text for openpyxl files) and DOCX tables come out merged ([[https://github.com/egao1980/doc-extract-protocol/issues/6][doc-extract-protocol#6]]).

** Python to CL examples
:PROPERTIES:
:UNNUMBERED: t
:END:
[[https://github.com/egao1980/python-to-cl/tree/master/examples][examples/report.xlsx and report.docx]] were written with openpyxl and python-docx: a sheet ~region / q1 / q2~ with two rows, a heading, a paragraph and a two-row table.

#+begin_src python
ws = load_workbook("examples/report.xlsx").active
[[c.value for c in row] for row in ws.iter_rows()]
" ".join(p.text for p in Document("examples/report.docx").paragraphs)
#+end_src

*** cl-stack
#+begin_src lisp :exports source :results silent
(asdf:load-system "doc-extract-protocol")
(asdf:load-system "compression-backend-chipz")

(defvar *extract* (stack-doc-extract:make-default-doc-extract-backend))
#+end_src

DOCX: the text is there; the table's cells run together:
#+begin_src lisp
(stack-doc-extract:extract-text *extract* #p"examples/report.docx" :format :docx)
