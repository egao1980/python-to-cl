https://saurabh-kumar.com/python-dotenv/

https://docs.pydantic.dev/latest/concepts/pydantic_settings/

Python-dotenv reads key-value pairs from a .env file and can set them as environment variables.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ python-dotenv: load ~.env~ into ~os.environ~, variable expansion, ~dotenv_values~
+ pydantic-settings: typed settings classes from env, ~.env~, secrets directories; nested keys; validation
+ stdlib: ~configparser~ (INI), ~tomllib~ (TOML)

A ~.env~ file by hand, until cl-stack-config reads them:
#+begin_src lisp
(defun load-dotenv (path)
  (with-open-file (in path)
    (loop for line = (read-line in nil)
          while line
          for eq = (position #\= line)
          when (and eq (not (eql (char line 0) #\#)))
            collect (let ((key (string-trim " " (subseq line 0 eq)))
                          (value (string-trim " \"" (subseq line (1+ eq)))))
                      (unless (uiop:getenv key) (sb-posix:setenv key value 1))
                      key))))

(with-open-file (s ".env" :direction :output :if-exists :supersede)
  (format s "# local settings~%APP_TOKEN=\"dev-token\"~%APP_DATABASE__HOST=db.local~%"))
(load-dotenv ".env")
(stack-config:get-string (stack-config:load #p"app.toml" :prefix "APP") "database.host")
#+end_src

#+RESULTS:
: db.local
