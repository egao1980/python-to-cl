* SymPy
:PROPERTIES:
:UNNUMBERED: t
:END:
https://docs.sympy.org/latest/

SymPy is a Python library for symbolic mathematics.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ Symbolic expressions: simplify, expand, factor
+ Calculus: derivatives, integrals, limits, series
+ Equation and ODE solving, matrices, number theory
+ ~lambdify~ to numeric functions, code generation, LaTeX output

** Common Lisp alternatives
:PROPERTIES:
:UNNUMBERED: t
:END:
The strongest answer on this site: [[https://maxima.sourceforge.io/][Maxima]], descended from MIT's Macsyma, is written in Common Lisp and runs on SBCL, CCL, ECL and ABCL. Expressions are s-expressions, so symbolic code is also natural in plain CL.

*** Plain CL
Derivatives of s-expressions, the classic Lisp exercise:
#+begin_src lisp
(defun simplify (e)
  (if (atom e)
      e
      (let ((args (mapcar #'simplify (rest e))))
        (case (first e)
          (+ (let ((terms (remove 0 args)))
               (cond ((null terms) 0) ((null (rest terms)) (first terms))
                     ((every #'numberp terms) (apply #'+ terms)) (t (cons '+ terms)))))
          (* (cond ((member 0 args) 0)
                   ((every #'numberp args) (apply #'* args))
                   (t (let ((factors (remove 1 args)))
                        (if (null (rest factors)) (first factors) (cons '* factors))))))
          (expt (if (eql (second args) 1) (first args) (cons 'expt args)))
          (t (cons (first e) args))))))

(defun d (e x)
  (simplify
   (cond ((numberp e) 0)
         ((symbolp e) (if (eq e x) 1 0))
         (t (destructuring-bind (op a &optional b) e
              (ecase op
                (+ `(+ ,(d a x) ,(d b x)))
                (* `(+ (* ,a ,(d b x)) (* ,(d a x) ,b)))
                (expt `(* ,b (expt ,a ,(1- b)) ,(d a x)))
                (sin `(* (cos ,a) ,(d a x)))))))))

(d '(+ (* 3 (expt x 2)) (sin x)) 'x)
#+end_src

#+RESULTS:
: (+ (* 3 (* 2 X)) (COS X))

~lambdify~ is ~compile~:
#+begin_src lisp
(funcall (compile nil `(lambda (x) ,(d '(+ (* 3 (expt x 2)) (sin x)) 'x))) 2d0)
#+end_src

#+RESULTS:
: 11.583853163452858d0
