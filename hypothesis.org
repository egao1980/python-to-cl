* Hypothesis
:PROPERTIES:
:UNNUMBERED: t
:END:
https://hypothesis.readthedocs.io/en/latest/

Hypothesis is a Python library for creating unit tests which are simpler to write and more powerful when run, finding edge cases in your code you wouldn't have thought to look for.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ ~@given~ with strategies: integers, text, lists, composite and recursive data
+ Shrinking: failing inputs reduced to a minimal example
+ Example database: failures replayed on the next run
+ Stateful testing (rule-based state machines); pytest integration

*** cl-stack
No property-based testing library. [[https://github.com/egao1980/spec-protocol][spec-protocol]] (0.1.1) does model-based testing instead: a ~defspec~ is checked with Quint, and the random traces it generates are replayed against the implementation (the Hypothesis stateful-testing role, from a formal model). The [[https://github.com/egao1980/rove][Rove fork]] (0.11.0) has ~deftest-parametrize~ for fixed tables.

#+begin_src lisp :results output
(fiveam:def-test reverse-twice ()
  (fiveam:for-all ((xs (fiveam:gen-list :elements (fiveam:gen-integer :min -100 :max 100))))
    (fiveam:is (equal xs (reverse (reverse xs))))))

(fiveam:run! 'reverse-twice)
#+end_src

A false property, "sorting removes nothing", fails on the first list with a duplicate:
#+begin_src lisp
(fiveam:def-test sort-keeps-length ()
  (fiveam:for-all ((xs (fiveam:gen-list :elements (fiveam:gen-integer :min 0 :max 3))))
    (fiveam:is (= (length xs) (length (remove-duplicates (sort (copy-list xs) #'<)))))))

(let ((result (first (fiveam:run 'sort-keeps-length))))
  (list (type-of result)
        (length (slot-value result 'it.bese.fiveam::failure-values))))
#+end_src

#+RESULTS:
: (IT.BESE.FIVEAM::FOR-ALL-TEST-FAILED 1)

FiveAM reports the failing values as generated, without shrinking them.
