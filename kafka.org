* Kafka / RabbitMQ / NATS clients
:PROPERTIES:
:UNNUMBERED: t
:END:
https://docs.confluent.io/platform/current/clients/confluent-kafka-python/html/index.html

https://pika.readthedocs.io/en/stable/

confluent-kafka-python provides a high-level Producer, Consumer and AdminClient compatible with all Apache Kafka brokers. Pika is a pure-Python implementation of the AMQP 0-9-1 protocol.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ confluent-kafka / kafka-python: producers, consumers, consumer groups, offsets, transactions
+ pika / aio-pika: RabbitMQ exchanges, queues, bindings, acks, prefetch
+ nats-py, paho-mqtt: NATS and MQTT
+ Schema registry with Avro / Protobuf payloads

*** cl-stack
#+begin_src lisp :exports source :results silent
(asdf:load-system "mq-backend-amqp")
(asdf:load-system "babel")

(defvar *mq* (stack-mq:make-in-memory-mq-backend))

(defun text (message) (babel:octets-to-string (stack-mq:mq-message-payload message)))
#+end_src

Publish, pull, acknowledge:
#+begin_src lisp
(stack-mq:publish *mq* "orders" (stack-mq:make-mq-message :payload "order-1"))
(stack-mq:publish *mq* "orders" (stack-mq:make-mq-message :payload "order-2"))

(let ((m (first (stack-mq:poll-messages *mq* "orders" :n 1))))
  (stack-mq:ack *mq* m)
  (text m))
#+end_src

#+RESULTS:
: order-1

~nack~ with requeue redelivers:
#+begin_src lisp
(let ((m (first (stack-mq:poll-messages *mq* "orders" :n 1))))
  (stack-mq:nack *mq* m :requeue t)
  (let ((again (first (stack-mq:poll-messages *mq* "orders" :n 1))))
    (list (text again) (stack-mq:mq-message-redelivered-p again))))
#+end_src

#+RESULTS:
: ("order-2" T)

Push consumer:
#+begin_src lisp
(let ((seen '()))
  (stack-mq:subscribe *mq* "events" (lambda (m) (push (text m) seen)))
  (stack-mq:publish *mq* "events" (stack-mq:make-mq-message :payload "user.created"))
  seen)
#+end_src

#+RESULTS:
: ("user.created")

The AMQP wire, what a backend writes for ~basic_publish~:
#+begin_src lisp
(let ((frame (mq-backend-amqp:encode-method-frame :basic-publish :channel 1
                                                  :exchange "" :routing-key "orders")))
  (list (length frame)
        (mq-backend-amqp:amqp-method-name (mq-backend-amqp:decode-method-frame frame))))
#+end_src

#+RESULTS:
: (23 :BASIC-PUBLISH)
