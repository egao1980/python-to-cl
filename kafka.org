* Kafka / RabbitMQ / NATS clients
:PROPERTIES:
:UNNUMBERED: t
:END:
https://docs.confluent.io/platform/current/clients/confluent-kafka-python/html/index.html

https://pika.readthedocs.io/en/stable/

confluent-kafka-python provides a high-level Producer, Consumer and AdminClient compatible with all Apache Kafka brokers. Pika is a pure-Python implementation of the AMQP 0-9-1 protocol.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ confluent-kafka / kafka-python: producers, consumers, consumer groups, offsets, transactions
+ pika / aio-pika: RabbitMQ exchanges, queues, bindings, acks, prefetch
+ nats-py, paho-mqtt: NATS and MQTT
+ Schema registry with Avro / Protobuf payloads

Fixed on 2026-11-24 – 26: both backends reach a broker on their own ([[https://github.com/egao1980/mq-backend-amqp/issues/2][mq-backend-amqp#2]], [[https://github.com/egao1980/mq-backend-kafka/issues/1][mq-backend-kafka#1]]), and [[https://github.com/egao1980/mq-parity][mq-parity]] 0.2.0 uses them. AMQP: an ack after a channel reopen acknowledges the right message ([[https://github.com/egao1980/mq-backend-amqp/issues/8][#8]]), IPv6 URLs ([[https://github.com/egao1980/mq-backend-amqp/issues/9][#9]]), no publish lost to a broker close (0.2.1, 0.2.2). Kafka: a poll no longer holds the session lock ([[https://github.com/egao1980/mq-backend-kafka/issues/5][#5]]), a revoked partition is never committed, rebalances deliver no duplicates (0.2.1, 0.2.2). Gaps: AMQP ~subscribe~ has no dispatch loop, deliveries come through ~poll-messages~ ([[https://github.com/egao1980/mq-backend-amqp/issues/5][mq-backend-amqp#5]]); review leftovers ([[https://github.com/egao1980/mq-backend-amqp/issues/14][#14]], [[https://github.com/egao1980/mq-backend-kafka/issues/8][mq-backend-kafka#8]]); no NATS or MQTT.

*** cl-stack
#+begin_src lisp :exports source :results silent
(asdf:load-system "mq-backend-amqp")
(asdf:load-system "babel")

(defvar *mq* (stack-mq:make-in-memory-mq-backend))

(defun text (message) (babel:octets-to-string (stack-mq:mq-message-payload message)))
#+end_src

Publish, pull, acknowledge:
#+begin_src lisp
(stack-mq:publish *mq* "orders" (stack-mq:make-mq-message :payload "order-1"))
(stack-mq:publish *mq* "orders" (stack-mq:make-mq-message :payload "order-2"))

(let ((m (first (stack-mq:poll-messages *mq* "orders" :n 1))))
  (stack-mq:ack *mq* m)
  (text m))
#+end_src

#+RESULTS:
: order-1

~nack~ with requeue redelivers:
#+begin_src lisp
(let ((m (first (stack-mq:poll-messages *mq* "orders" :n 1))))
  (stack-mq:nack *mq* m :requeue t)
  (let ((again (first (stack-mq:poll-messages *mq* "orders" :n 1))))
    (list (text again) (stack-mq:mq-message-redelivered-p again))))
#+end_src

#+RESULTS:
: ("order-2" T)

Push consumer:
#+begin_src lisp
(let ((seen '()))
  (stack-mq:subscribe *mq* "events" (lambda (m) (push (text m) seen)))
  (stack-mq:publish *mq* "events" (stack-mq:make-mq-message :payload "user.created"))
  seen)
#+end_src

#+RESULTS:
: ("user.created")

The AMQP wire, what a backend writes for ~basic_publish~:

(let ((frame (mq-backend-amqp:encode-method-frame :basic-publish :channel 1

(mq-backend-amqp:with-amqp-backend (b :url "amqp://guest:guest@127.0.0.1:15672/%2f")
  (mq-backend-amqp:amqp-declare-queue b "orders")

#+end_src

Kafka 3.9 in Docker (~apache/kafka-native:3.9.0~, one KRaft node on 127.0.0.1:19092), confluent-kafka's ~Producer~ / ~Consumer~ with a group; librdkafka 2.16.0 comes from cl-repo:
#+begin_src lisp :exports source :results silent
(asdf:load-system "mq-backend-kafka")
#+end_src

#+begin_src lisp
(let ((p (mq-backend-kafka:make-kafka-backend :bootstrap-servers "127.0.0.1:19092")))
  (unwind-protect
       (progn (stack-mq:publish p "orders" (stack-mq:make-mq-message :key "customer-7" :payload "order-1"))
              (mq-backend-kafka:kafka-flush p))
    (close p)))

(let ((c (mq-backend-kafka:make-kafka-backend :bootstrap-servers "127.0.0.1:19092" :group-id "demo")))
  (unwind-protect
       (let ((m (first (stack-mq:poll-messages c "orders" :timeout 20))))
         (stack-mq:ack c m)                   ; commits the offset
         (list (text m) (stack-mq:mq-message-key m)))
    (close c)))
#+end_src

#+RESULTS:
: ("order-1" "customer-7")
