* OpenAI / Anthropic SDKs
:PROPERTIES:
:UNNUMBERED: t
:END:
https://github.com/openai/openai-python

https://github.com/anthropics/anthropic-sdk-python

The OpenAI Python library provides convenient access to the OpenAI REST API from any Python 3.9+ application.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ openai: Chat Completions and Responses APIs, streaming, tool calls, structured outputs, embeddings, images, audio, batches
+ anthropic: Messages API, streaming, tool use, prompt caching, extended thinking
+ Typed request and response objects, retries, timeouts, async clients
+ LiteLLM: one interface over many providers, routing and fallbacks; tiktoken: token counts

** Python to CL examples
:PROPERTIES:
:UNNUMBERED: t
:END:
No API keys here: the examples talk to a local mock of both APIs, [[https://github.com/egao1980/python-to-cl/blob/master/examples/mock-llm.lisp][examples/mock-llm.lisp]] (Hunchentoot). The same calls go to the real services by changing ~:base-url~ and the key.

#+begin_src python
client = OpenAI(base_url="http://127.0.0.1:18080/v1", api_key="sk-test")
r = client.chat.completions.create(model="gpt-4o-mini", messages=[{"role": "user", "content": "ping"}])
r.choices[0].message.content
#+end_src

*** cl-stack
https://github.com/egao1980/cl-stack/blob/main/docs/cookbooks/llm.md

#+begin_src lisp :exports source :results silent
(load "examples/mock-llm.lisp")
(mock-llm:start-mock)

(asdf:load-system "llm-protocol-openai")
(asdf:load-system "llm-protocol-anthropic")
(asdf:load-system "http-backend-async")
(asdf:load-system "event-backend-libuv")

(setf http-backend-async:*event-backend-maker* #'event-backend-libuv:make-libuv-backend
      http-protocol:*http-backend* (http-backend-async:make-async-backend))

(defvar *openai* (stack-llm-openai:make-openai-compat-backend
                  :base-url "http://127.0.0.1:18080/v1" :api-key "sk-test"
                  :default-model "gpt-4o-mini"))
#+end_src

#+begin_src lisp
(stack-llm:llm-response-text (stack-llm:generate *openai* "ping"))
#+end_src

#+RESULTS:
: echo: ping

Tool calls:
#+begin_src lisp
(let ((r (stack-llm:generate
          *openai* "Weather in Paris?"
          :tools (list (stack-llm:make-llm-tool
                        :name "get_weather" :description "Current weather for a city"
                        :parameters (com.inuoe.jzon:parse
                                     "{\"type\":\"object\",\"properties\":{\"city\":{\"type\":\"string\"}}}"))))))
  (list (stack-llm:llm-response-finish-reason r)
        (mapcar (lambda (c) (list (stack-llm:llm-tool-call-part-name c)
                                  (stack-llm:llm-tool-call-part-arguments c)))
                (stack-llm:llm-response-tool-calls r))))
#+end_src

#+RESULTS:
: (:TOOL-USE (("get_weather" "{\"city\":\"Paris\"}")))
