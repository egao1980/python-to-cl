Review leftovers from the previous round, taken one at a time. Every version below is on GHCR.

- [[file+emacs:email.org][email]]: mail-protocol 0.3.3 refuses CR / LF / NUL in IMAP arguments, so an argument can no longer end the command and start another. It also sends literals for non-ASCII text and encodes mailbox names in modified UTF-7 ([[https://github.com/egao1980/mail-protocol/issues/9][mail-protocol#9]], PR [[https://github.com/egao1980/mail-protocol/pull/15][#15]]).
- [[file+emacs:email.org][email]]: encoding-protocol 0.3.1 maps MIME / IANA charset names and Python's aliases: ~shift_jis~, ~windows-31j~, ~euc-jp~, ~gb2312~, ~gbk~, ~koi8-r~ / ~-u~ and the ISO-8859 aliases. A character that a charset can't encode now signals ~encoding-transcode-error~ with the code point and index; before, koi8-r gave a type error. A charset it lacks signals ~encoding-unknown-encoding~ with a ~use-value~ restart ([[https://github.com/egao1980/encoding-protocol/issues/5][encoding-protocol#5]], PR [[https://github.com/egao1980/encoding-protocol/pull/6][#6]]). Python differences: ~shift_jis~ is CP932 and ~gb2312~ is GBK, both supersets, and EUC-JP has no JIS X 0212 ([[https://github.com/egao1980/encoding-protocol/issues/8][#8]]). mime-protocol and mail-protocol don't pass these names through yet ([[https://github.com/egao1980/mime-protocol/issues/22][mime-protocol#22]], [[https://github.com/egao1980/mail-protocol/issues/17][mail-protocol#17]]).
- [[file+emacs:requests.org][Requests]]: http-backend-async 0.2.32 reads a body with no length to the end of the connection. Before, it stopped at the first pause in the data ([[https://github.com/egao1980/http-backend-async/issues/89][http-backend-async#89]], PR [[https://github.com/egao1980/http-backend-async/pull/90][#90]]).
- [[file+emacs:langchain.org][LangChain / MCP SDK]]: ai-agent-protocol 0.17.1 uses llm-protocol's retry helpers instead of redefining them ([[https://github.com/egao1980/ai-agent-protocol/issues/50][ai-agent-protocol#50]], PR [[https://github.com/egao1980/ai-agent-protocol/pull/56][#56]]). cl-stack-code 0.16.1 compiles with no full WARNING, and a turn timeout is in seconds ([[https://github.com/egao1980/cl-stack-code/issues/67][cl-stack-code#67]], [[https://github.com/egao1980/cl-stack-code/issues/60][#60]], PR [[https://github.com/egao1980/cl-stack-code/pull/68][#68]]).
- [[file+emacs:jupyter.org][Jupyter]]: lisp-mcp 0.7.4 can locate, replace and delete top-level comment blocks (lisp-source-protocol 0.2.7, PR [[https://github.com/egao1980/lisp-source-protocol/pull/19][lisp-source-protocol#19]]). It also requires current versions of its dependencies, and its ~serverInfo~ reports the real version (PR [[https://github.com/egao1980/lisp-mcp/pull/36][lisp-mcp#36]]).
- [[file+emacs:packaging.org][pip / uv]]: cl-repo client 0.27.40 starts on ECL, CCL and ABCL as well as SBCL, and a lock entry below a version floor gives way to the floor ([[https://github.com/egao1980/cl-repository/issues/190][cl-repository#190]], [[https://github.com/egao1980/cl-repository/issues/203][#203]], [[https://github.com/egao1980/cl-repository/issues/196][#196]], PR [[https://github.com/egao1980/cl-repository/pull/204][#204]]).

- [[file+emacs:email.org][email]]: encoding-protocol 0.4.0 adds the charsets Babel lacks ([[https://github.com/egao1980/encoding-protocol/issues/7][encoding-protocol#7]], PR [[https://github.com/egao1980/encoding-protocol/pull/10][#10]]). The core gets windows-1250 and 1253 – 1258, cp866, mac-roman, tis-620 and cp874. iso-2022-jp, Big5, EUC-KR, CP949 (~ks_c_5601-1987~) and GB18030 go in the optional system ~encoding-protocol/cjk~, which adds about 244 KB of fasl. ~normalize-encoding~ returns, as a second value, the system to load for a name, and ~encoding-unknown-encoding~ names it. The tables are generated from Python's codecs, checked over every byte and code point, and tested against Python on all three OSes. Not yet: big5-hkscs, hz, utf-7, iso-2022-jp-2 and iso-2022-kr ([[https://github.com/egao1980/encoding-protocol/issues/11][#11]]).

- [[file+emacs:email.org][email]]: mail-protocol 0.3.4 ([[https://github.com/egao1980/mail-protocol/issues/16][mail-protocol#16]], PR [[https://github.com/egao1980/mail-protocol/pull/18][#18]]):
  - ~imap-utf7-decode~ accepts only the canonical form, as RFC 3501 requires.
  - ~imap-select~ selects only on OK and signals ~imap-error~ on NO or BAD.
  - Binary streams read a server's non-UTF-8 reply text on any Lisp.
  - ~imap-append~ and ~imap-store~ are new. An ~imap-literal~ is the only argument that may carry CR LF.
- [[file+emacs:email.org][email]]: mail-protocol 0.3.5 ([[https://github.com/egao1980/mail-protocol/issues/13][#13]], PR [[https://github.com/egao1980/mail-protocol/pull/19][#19]]):
  - A comment between encoded words separates them, as in Python.
  - Non-ASCII comments are encoded, and re-encoded addresses keep their comments.
  - An address that doesn't parse is refused, ASCII or not.
  - SMTP has a ~:read-timeout~, 600 s by default (RFC 5321). Before, SBCL reused the 30 s connect timeout.

HTTP:

- [[file+emacs:requests.org][Requests]], [[file+emacs:httpx.org][HTTPX]]: an ~https://~ proxy is reached over TLS; before, the request and ~Proxy-Authorization~ went to it in cleartext ([[https://github.com/egao1980/http-protocol/issues/53][http-protocol#53]]). http-protocol 0.4.5 (~proxy-kind :https~), http-backend-async 0.2.29 (TLS to the proxy, TLS inside TLS for ~https~ origins), http-backend-dexador 0.2.2 refuses with ~proxy-tls-unsupported~ and a ~use-value~ restart. PRs [[https://github.com/egao1980/http-protocol/pull/60][http-protocol#60]], [[https://github.com/egao1980/http-backend-async/pull/81][http-backend-async#81]], [[https://github.com/egao1980/http-backend-dexador/pull/38][http-backend-dexador#38]], demo [[https://github.com/egao1980/cl-stack-demos/tree/main/harness/http-facade][harness/http-facade]].
- [[file+emacs:requests.org][Requests]]: http-backend-async 0.2.30 builds each redirect hop for its own URL: the proxy is picked again, ~Proxy-Authorization~ never enters a tunnel, ~Authorization~ is dropped on another origin ([[https://github.com/egao1980/http-backend-async/issues/82][http-backend-async#82]]). PR [[https://github.com/egao1980/http-backend-async/pull/83][http-backend-async#83]], demo [[https://github.com/egao1980/cl-stack-demos/tree/main/harness/http-facade][harness/http-facade]].
- [[file+emacs:requests.org][Requests]]: http-backend-dexador 0.2.1 sends form posts and multipart bodies ([[https://github.com/egao1980/http-backend-dexador/issues/32][http-backend-dexador#32]]) and follows redirects itself, so ~response-history~ has the hops ([[https://github.com/egao1980/http-backend-dexador/issues/33][#33]]). - [[file+emacs:requests.org][Requests]], [[file+emacs:httpx.org][HTTPX]]: cl-stack-http 0.2.1: a session's ~:proxy~ wins over the environment, a request's over both, as in requests ([[https://github.com/egao1980/cl-stack-http/issues/34][cl-stack-http#34]], [[https://github.com/egao1980/cl-stack-http/issues/35][#35]], PR [[https://github.com/egao1980/cl-stack-http/pull/36][#36]]). On Windows ~:total~ bounds the whole WinHTTP call (http-backend-dexador 0.2.3, [[https://github.com/egao1980/http-backend-dexador/issues/29][#29]], PR [[https://github.com/egao1980/http-backend-dexador/pull/40][#40]]).
