The cl-stack gaps these pages linked were worked on, each with an issue, a pull request, a GHCR release and a demo in [[https://github.com/egao1980/cl-stack-demos/tree/main/harness][cl-stack-demos]]. The pages below show the new results.

Fixed and published:
- [[file+emacs:requests.org][Requests]], [[file+emacs:httpx.org][HTTPX]]: cl-stack-http 0.2.0 exports the response readers and conditions ([[https://github.com/egao1980/cl-stack-http/issues/26][cl-stack-http#26]]); ~:auto~ sends ~-async~ calls to the async backend with no setup ([[https://github.com/egao1980/cl-stack-http/issues/27][#27]]). PR [[https://github.com/egao1980/cl-stack-http/pull/30][cl-stack-http#30]], demo [[https://github.com/egao1980/cl-stack-demos/tree/main/harness/http-facade][harness/http-facade]].
- [[file+emacs:requests.org][Requests]]: http-backend-dexador 0.2.0 takes proxies from the environment ([[https://github.com/egao1980/http-backend-dexador/issues/23][http-backend-dexador#23]]) and enforces read timeouts on HTTPS, also after a redirect ([[https://github.com/egao1980/http-backend-dexador/issues/24][#24]]), on dexador 0.9.16.1 from the egao1980 fork. PR [[https://github.com/egao1980/http-backend-dexador/pull/27][http-backend-dexador#27]], demo [[https://github.com/egao1980/cl-stack-demos/tree/main/harness/dexador-http][harness/dexador-http]].
- [[file+emacs:asyncio.org][asyncio]], [[file+emacs:httpx.org][HTTPX]], [[file+emacs:multiprocessing.org][multiprocessing]]: event-protocol 0.3.0 has ~run-promise~ (~asyncio.run~), ~gather~ and ~await~ on a promise with ~:timeout~ ([[https://github.com/egao1980/event-protocol/issues/26][event-protocol#26]]). PR [[https://github.com/egao1980/event-protocol/pull/28][event-protocol#28]], demo [[https://github.com/egao1980/cl-stack-demos/tree/main/harness/http-facade][harness/http-facade]].
- [[file+emacs:pdf.org][PDF]]: doc-extract-backend-pdf 0.1.5 (now 0.2.0) reads unencrypted files without a password ([[https://github.com/egao1980/doc-extract-backend-pdf/issues/9][doc-extract-backend-pdf#9]]). PR [[https://github.com/egao1980/doc-extract-backend-pdf/pull/13][doc-extract-backend-pdf#13]], demo [[https://github.com/egao1980/cl-stack-demos/tree/main/harness/documents][harness/documents]].
- [[file+emacs:openpyxl.org][openpyxl]]: doc-extract-protocol 0.4.0 reads XLSX worksheets and keeps DOCX table cells apart, on compression-protocol 0.5.1 and xml-backend-native 0.1.1 ([[https://github.com/egao1980/doc-extract-protocol/issues/6][doc-extract-protocol#6]]). PRs [[https://github.com/egao1980/doc-extract-protocol/pull/8][doc-extract-protocol#8]], [[https://github.com/egao1980/compression-protocol/pull/11][compression-protocol#11]], demo [[https://github.com/egao1980/cl-stack-demos/tree/main/harness/documents][harness/documents]].

PR [[https://github.com/egao1980/yaml-protocol/pull/8][yaml-protocol#8]], demo [[https://github.com/egao1980/cl-stack-demos/tree/main/harness/documents][harness/documents]].
- [[file+emacs:dotenv.org][python-dotenv]]: cl-stack-config 0.3.0 reads ~.env~ files and fills ~defschema~ settings ([[https://github.com/egao1980/cl-stack-config/issues/8][cl-stack-config#8]]).
