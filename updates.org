* 2026-11-24 – 26
:PROPERTIES:

The gaps the 2026-11-23 list left open were closed, most of them after an adversarial review round each. Every version below is on GHCR. Demos are in [[https://github.com/egao1980/cl-stack-demos/tree/main/harness][cl-stack-demos]].

HTTP:
- [[file+emacs:requests.org][Requests]]: http-protocol 0.4.4 draws multipart boundaries at random (128 bits, collision-checked) and refuses part content that is not octets ([[https://github.com/egao1980/http-protocol/issues/56][http-protocol#56]], [[https://github.com/egao1980/http-protocol/issues/57][#57]]). PR [[https://github.com/egao1980/http-protocol/pull/58][http-protocol#58]], demo [[https://github.com/egao1980/cl-stack-demos/tree/main/harness/mime-multipart][harness/mime-multipart]].
- [[file+emacs:requests.org][Requests]], [[file+emacs:httpx.org][HTTPX]]: an ~https://~ proxy is reached over TLS; before, the request and ~Proxy-Authorization~ went to it in cleartext ([[https://github.com/egao1980/http-protocol/issues/53][http-protocol#53]]). http-protocol 0.4.5 (~proxy-kind :https~), http-backend-async 0.2.29 (TLS to the proxy, TLS inside TLS for ~https~ origins), http-backend-dexador 0.2.2 refuses with ~proxy-tls-unsupported~ and a ~use-value~ restart. PRs [[https://github.com/egao1980/http-protocol/pull/60][http-protocol#60]], [[https://github.com/egao1980/http-backend-async/pull/81][http-backend-async#81]], [[https://github.com/egao1980/http-backend-dexador/pull/38][http-backend-dexador#38]], demo [[https://github.com/egao1980/cl-stack-demos/tree/main/harness/http-facade][harness/http-facade]].
- [[file+emacs:requests.org][Requests]]: http-backend-async 0.2.30 builds each redirect hop for its own URL: the proxy is picked again, ~Proxy-Authorization~ never enters a tunnel, ~Authorization~ is dropped on another origin ([[https://github.com/egao1980/http-backend-async/issues/82][http-backend-async#82]]). PR [[https://github.com/egao1980/http-backend-async/pull/83][http-backend-async#83]], demo [[https://github.com/egao1980/cl-stack-demos/tree/main/harness/http-facade][harness/http-facade]].
- [[file+emacs:requests.org][Requests]]: http-backend-dexador 0.2.1 sends form posts and multipart bodies ([[https://github.com/egao1980/http-backend-dexador/issues/32][http-backend-dexador#32]]) and follows redirects itself, so ~response-history~ has the hops ([[https://github.com/egao1980/http-backend-dexador/issues/33][#33]]). PR [[https://github.com/egao1980/http-backend-dexador/pull/34][http-backend-dexador#34]], demo [[https://github.com/egao1980/cl-stack-demos/tree/main/harness/dexador-http][harness/dexador-http]].
- [[file+emacs:requests.org][Requests]], [[file+emacs:httpx.org][HTTPX]]: cl-stack-http 0.2.1: a session's ~:proxy~ wins over the environment, a request's over both, as in requests ([[https://github.com/egao1980/cl-stack-http/issues/34][cl-stack-http#34]], [[https://github.com/egao1980/cl-stack-http/issues/35][#35]], PR [[https://github.com/egao1980/cl-stack-http/pull/36][#36]]). Redirect methods follow RFC 9110: 301 / 302 turn only POST into GET, 303 keeps HEAD (http-backend-async 0.2.31, [[https://github.com/egao1980/http-backend-async/issues/84][http-backend-async#84]], [[https://github.com/egao1980/http-backend-async/issues/85][#85]], PR [[https://github.com/egao1980/http-backend-async/pull/87][#87]]; http-backend-dexador 0.2.4, PR [[https://github.com/egao1980/http-backend-dexador/pull/42][http-backend-dexador#42]]). On Windows ~:total~ bounds the whole WinHTTP call (http-backend-dexador 0.2.3, [[https://github.com/egao1980/http-backend-dexador/issues/29][#29]], PR [[https://github.com/egao1980/http-backend-dexador/pull/40][#40]]). A Content-Type with no body is sent (0.2.5, [[https://github.com/egao1980/http-backend-dexador/issues/36][#36]], PR [[https://github.com/egao1980/http-backend-dexador/pull/37][#37]]). Demo [[https://github.com/egao1980/cl-stack-demos/tree/main/harness/http-facade][harness/http-facade]].
