* SciPy / statsmodels
:PROPERTIES:
:UNNUMBERED: t
:END:
https://docs.scipy.org/doc/scipy/

https://www.statsmodels.org/stable/

SciPy provides algorithms for optimization, integration, interpolation, eigenvalue problems, algebraic equations, differential equations, statistics and many other classes of problems.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ ~optimize~ (minimize, root finding, linprog), ~integrate~ (quad, ODEs), ~interpolate~
+ ~linalg~ (LAPACK), ~sparse~, ~fft~, ~signal~
+ ~stats~: distributions, tests, descriptive statistics; ~special~ functions
+ statsmodels: regression models, time series, statistical tests

*** Plain CL
~fractions~ / ~decimal~ come built in:
#+begin_src python
Fraction(1, 3) + Fraction(1, 6), math.comb(50, 25), cmath.sqrt(-4)
#+end_src

#+begin_src lisp
(list (+ 1/3 1/6)
      (let ((n 50) (k 25)) (/ (reduce #'* (loop for i from (1+ (- n k)) to n collect i))
                              (reduce #'* (loop for i from 1 to k collect i))))
      (sqrt -4))
#+end_src

#+RESULTS:
: (1/2 126410606437752 #C(0.0 2.0))

~scipy.optimize.newton~ and ~scipy.integrate.quad~, by hand:
#+begin_src lisp
(defun newton (f df x &key (tolerance 1d-12))
  (loop for step = (/ (funcall f x) (funcall df x))
        do (decf x step)
        until (< (abs step) tolerance)
        finally (return x)))

(defun simpson (f a b &key (n 1000))
  (let ((h (/ (- b a) n)))
    (* (/ h 3) (loop for i from 0 to n
                     sum (* (funcall f (+ a (* i h)))
                            (cond ((or (= i 0) (= i n)) 1) ((oddp i) 4) (t 2)))))))

(list (newton (lambda (x) (- (* x x) 2)) (lambda (x) (* 2 x)) 1d0)
      (simpson (lambda (x) (exp (- (* x x)))) 0d0 3d0))
#+end_src

#+RESULTS:
: (1.414213562373095d0 0.8862073482595123d0)

Mean, sample standard deviation, ~statistics.stdev~:
#+begin_src lisp
(let* ((xs '(2 4 4 4 5 5 7 9))
       (n (length xs))
       (mean (/ (reduce #'+ xs) n)))
  (list mean (sqrt (/ (reduce #'+ (mapcar (lambda (x) (expt (- x mean) 2)) xs)) (1- n)))))
#+end_src

#+RESULTS:
: (5 2.13809)
