* Paramiko / Fabric
:PROPERTIES:
:UNNUMBERED: t
:END:
https://docs.paramiko.org/en/stable/

https://www.fabfile.org/

Paramiko is a pure-Python implementation of the SSHv2 protocol, providing both client and server functionality.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ SSH client: connect, authenticate (keys, agent, password), run commands
+ SFTP: upload, download, list, stat
+ Host key checking, ~known_hosts~, port forwarding, an SSH server
+ Fabric: remote tasks over many hosts; asyncssh: the asyncio version

** Python to CL examples
:PROPERTIES:
:UNNUMBERED: t
:END:
#+begin_src python
client = paramiko.SSHClient()
client.load_system_host_keys()
client.connect("host.example.com", username="deploy")
stdin, stdout, stderr = client.exec_command("uname -s")
#+end_src

*** OpenSSH through process-protocol
The local client works; a remote command needs a host, so the second form is not run:
#+begin_src lisp :exports source :results silent
(asdf:load-system "process-backend-uiop")
#+end_src

#+begin_src lisp
(multiple-value-bind (code out err) (stack-process:run '("ssh" "-V"))
  (declare (ignore out))
  (list code (string-trim '(#\Newline) (babel:octets-to-string err))))
#+end_src
