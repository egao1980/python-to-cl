* Celery / RQ / APScheduler
:PROPERTIES:
:UNNUMBERED: t
:END:
https://docs.celeryq.dev/en/stable/

https://python-rq.org/

Celery is a simple, flexible, and reliable distributed system to process vast amounts of messages, while providing operations with the tools required to maintain such a system.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ Celery: tasks sent through a broker (RabbitMQ, Redis) to worker pools; results backend
+ Retries, ETA / countdown, rate limits; canvas: chains, groups, chords
+ Periodic tasks (beat), cron schedules
+ RQ: Redis queues and simple workers; APScheduler / schedule: in-process scheduling

** Common Lisp alternatives
:PROPERTIES:
:UNNUMBERED: t
:END:

*** cl-stack
https://github.com/egao1980/task-protocol

#+begin_src lisp :exports source :results silent
(asdf:load-system "task-protocol")

(defvar *journal* (stack-task:make-in-memory-journal))
(defvar *charges* 0)
#+end_src

A step that must not run twice, Celery's ~acks_late~ + idempotency key:
#+begin_src lisp
(defun charge-invoice ()
  (let ((task (stack-task:make-durable-task :id "invoice-42")))
    (stack-task:with-durable-task (task *journal*)
      (stack-task:with-durable-step ("charge" :idempotency-key "inv-42")
        (incf *charges*)
        '(:charged 100)))))

(list (charge-invoice) (charge-invoice) *charges*)
#+end_src

#+RESULTS:
: ((:CHARGED 100) (:CHARGED 100) 1)

The second run replayed the recorded result. The journal:
#+begin_src lisp
(mapcar #'type-of (stack-task:journal-events *journal* (stack-task:make-durable-task :id "invoice-42")))
#+end_src

#+RESULTS:
: (TASK-PROTOCOL:TASK-STARTED TASK-PROTOCOL:STEP-COMPLETED)

A cron schedule, beat's ~crontab(minute=0, hour=3)~:
#+begin_src lisp
(let* ((journal (stack-task:make-in-memory-journal))
       (task (stack-task:make-durable-task :id "nightly" :journal journal))
       (t0 (encode-universal-time 0 30 2 1 12 2026 0)))   ; 02:30 UTC
  (stack-task:schedule-recurring task '(:minute 0 :hour 3) :now t0)
  (list (length (stack-task:fire-due-timers journal (+ t0 600)))      ; 02:40
        (length (stack-task:fire-due-timers journal (+ t0 3600)))))   ; 03:30
#+end_src

#+RESULTS:
: (0 1)

*** SBCL timers
The ~schedule~ library role, in the image:
#+begin_src lisp
(let* ((ticks 0)
       (timer (sb-ext:make-timer (lambda () (incf ticks)) :thread t)))
  (sb-ext:schedule-timer timer 0.1 :repeat-interval 0.1)
  (sleep 0.35)
  (sb-ext:unschedule-timer timer)
  ticks)
#+end_src

#+RESULTS:
: 3
