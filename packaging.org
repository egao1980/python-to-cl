* pip / Poetry / uv
:PROPERTIES:
:UNNUMBERED: t
:END:
https://docs.astral.sh/uv/

https://python-poetry.org/docs/

An extremely fast Python package and project manager, written in Rust.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ pip: install from PyPI; venv: isolated environments
+ Poetry / uv: ~pyproject.toml~ projects, dependency resolution, lock files, workspaces
+ uv: Python version management, tool runs (~uvx~), very fast installs
+ Build and publish wheels; PyInstaller: single-file executables

** Common Lisp alternatives
:PROPERTIES:
:UNNUMBERED: t
:END:

*** cl-stack
| Library                                                                  | Version | Verdict                                                                                                                                                                                                                           |
|--------------------------------------------------------------------------+---------+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [[https://github.com/egao1980/cl-repository][cl-repository]] (~cl-repo~) | 0.27.36 | OCI packages on GHCR (~ghcr.io/egao1980/cl-systems~) with native libraries per platform; dependencies from the ~.asd~, a ~cl-repo.lock~; ~sync~ / ~test~ / ~run~ / ~ros~ / ~publish~. Every example on this site runs through it. |

Fixed on 2026-11-23 in 0.27.35 ([[https://github.com/egao1980/cl-repository/pull/174][cl-repository#174]]): ~cl-repo ros~ starts without Roswell's Quicklisp (~-Q~ brings it back, [[https://github.com/egao1980/cl-repository/issues/166][#166]]); the lock records each package's registry and digest, so a fresh machine syncs from it ([[https://github.com/egao1980/cl-repository/issues/163][#163]]); ~sync~ resolves to the newest published version ([[https://github.com/egao1980/cl-repository/issues/167][#167]]) and names the versions the registry has when a minimum is missing ([[https://github.com/egao1980/cl-repository/issues/165][#165]]); a qlfile-only project gets its entries' dependencies ([[https://github.com/egao1980/cl-repository/issues/170][#170]]); parallel runs on SBCL no longer race on the shared fasl cache ([[https://github.com/egao1980/cl-repository/issues/162][#162]]; other Lisps and Windows: [[https://github.com/egao1980/cl-repository/issues/173][#173]]); the misleading "stays loaded" warning is gone ([[https://github.com/egao1980/cl-repository/issues/169][#169]]; the image did load the lock's versions). 0.27.36 stops implementation systems such as ~uiop~ from becoming solver requests ([[https://github.com/egao1980/cl-repository/issues/171][#171]]). Gaps: with no registry reachable, ~sync~ takes minutes ([[https://github.com/egao1980/cl-repository/issues/179][#179]]); the client tree and the install tree share a fasl root ([[https://github.com/egao1980/cl-repository/issues/182][#182]]).

#+begin_src sh

*** cl-repo
#+begin_src sh
mkdir demo && cd demo
echo '(defsystem "demo" :depends-on ("dexador"))' > demo.asd
cl-repo sync                 # resolves, installs, writes cl-repo.lock
cl-repo ros run              # a REPL with the project's systems and no Quicklisp
#+end_src

What the examples' project resolved, from inside its image:
