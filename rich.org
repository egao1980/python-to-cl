Rich is a Python library for rich text and beautiful formatting in the terminal.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ Rich: colours and styles, tables, panels, Markdown, syntax highlighting, tracebacks, live displays
+ tqdm: progress bars around any iterable
+ prompt_toolkit: line editing, history, completion, full-screen apps
+ Textual: full TUI applications with widgets, layout, CSS, mouse

*** cl-stack
A Textual-style app: model, update, view:
#+begin_src lisp :results silent
(defclass counter () ())

(defmethod stack-tui:tui-init ((app counter)) (values 0 nil))

(defmethod stack-tui:tui-update ((app counter) n (m stack-tui:key-message))
  (case (stack-tui:key-message-key m)
    (:equal (values (1+ n) nil))        ; "+"
    (:q (values n :quit))
    (t (values n nil))))

(defmethod stack-tui:tui-update ((app counter) n m) (values n nil))

(defmethod stack-tui:tui-view ((app counter) n canvas)
  (stack-tui:draw-box canvas 0 0 20 3 :title "counter")
  (stack-tui:draw-text canvas 2 1 (format nil "count: ~D" n)))
#+end_src

Driven headless, Textual's ~app.run_test()~ / ~pilot.press~:
#+begin_src lisp
(let ((tui (tui-backend-terminal:make-headless-tui (make-instance 'counter) :cols 20 :rows 3)))
  (tui-backend-terminal:tui-wait-for tui "count: 0")
  (tui-backend-terminal:tui-type tui "+++")
  (tui-backend-terminal:tui-wait-for tui "count: 3")
  (prog1 (tui-backend-terminal:tui-screen tui)
    (tui-backend-terminal:tui-type tui "q")
    (tui-backend-terminal:tui-stop tui)))
#+end_src

#+RESULTS:
: ("┌─counter──────────┐" "│ count: 3         │" "└──────────────────┘")

The same program runs on the real terminal with ~(stack-tui:run-tui (make-instance 'counter) :backend (tui-backend-tty:make-tty-backend))~.

Markdown, ~Markdown(...)~ in Rich, as plain text of the styled lines:
#+begin_src lisp
(mapcar (lambda (line) (format nil "~{~a~}" (mapcar #'stack-tui-widgets:text-run-text line)))
        (stack-tui-md:render-markdown (format nil "# Title~%Some **bold** text and a [link](https://example.com).") 40))
#+end_src

#+RESULTS:
