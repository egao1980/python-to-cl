https://matplotlib.org/stable/

https://plotly.com/python/

Matplotlib is a comprehensive library for creating static, animated, and interactive visualizations in Python.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ Line, bar, scatter, histogram, image, contour, 3D plots
+ Figures with subplots, axes, legends, annotations
+ PNG, SVG, PDF output; interactive windows; notebook inline display
+ Plotly: interactive HTML charts, dashboards (Dash)

** Common Lisp alternatives
:PROPERTIES:
:UNNUMBERED: t

(asdf:load-system "canvas-backend-svg")
#+end_src

A line chart as SVG:
#+begin_src lisp :post shorten(*this*)
(defparameter *squares*
  (canvas:make-chart :line
                     :title "Squares"
                     :series (list (canvas:make-series "x²" (loop for x from 0 to 10 collect (cons x (* x x)))))
                     :x-axis (canvas:make-axis :label "x")
                     :y-axis (canvas:make-axis :label "x²")))

(canvas:to-html *squares*)
#+end_src

#+RESULTS:
: <figure data-chart="line"><svg id="chart-squares" viewBox="0 0 640 360" role="img" aria-labelledby="chart-squares-tit...

Save it, then a histogram:
#+begin_src lisp
(with-open-file (s "squares.svg.html" :direction :output :if-exists :supersede)
  (write-string (canvas:to-html *squares*) s))

(let ((h (canvas:make-chart :histogram :title "Rolls" :bins 6
                            :series (list (canvas:make-series "d6" (loop repeat 600 collect (1+ (random 6))))))))
  (length (canvas:to-html h)))
#+end_src

#+RESULTS:
: 2381

~freeze~ turns a canvas function into one static HTML page:
#+begin_src lisp
(defun squares-page (&key) (canvas:card (list *squares*) :title "Report"))

(let ((html (canvas:freeze 'squares-page :title "Report")))
  (with-open-file (s "report.html" :direction :output :if-exists :supersede)
    (write-string html s))
  (list (length html) (search "<svg" html) (search "<script" html)))
#+end_src

#+RESULTS:
: (8770 5620 NIL)
