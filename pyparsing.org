* pyparsing / Lark
:PROPERTIES:
:UNNUMBERED: t
:END:
https://pyparsing-docs.readthedocs.io/en/latest/

https://lark-parser.readthedocs.io/en/stable/

The pyparsing module is an alternative approach to creating and executing simple grammars, vs. the traditional lex/yacc approach, or the use of regular expressions.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ pyparsing: grammars built from Python objects (~Word~, ~Literal~, ~Forward~), parse actions, named results
+ Lark: EBNF grammars, Earley and LALR(1), parse trees and transformers
+ ply: lex / yacc
+ Error positions and messages

:UNNUMBERED: t

*** esrap
https://scymtym.github.io/esrap/

#+begin_src python
integer = pp.Word(pp.nums).set_parse_action(lambda t: int(t[0]))
expr = pp.infix_notation(integer, [(pp.one_of("* /"), 2, pp.OpAssoc.LEFT),
                                   (pp.one_of("+ -"), 2, pp.OpAssoc.LEFT)])
expr.parse_string("2 * (3 + 4) - 5")
#+end_src

#+begin_src lisp :exports source :results silent
(asdf:load-system "esrap")

(defpackage #:calc (:use #:cl #:esrap))
(in-package #:calc)

(defun fold-left (first rest)
  "REST is a list of (op value); apply each op to the running value."
  (reduce (lambda (acc x) (funcall (first x) acc (second x))) rest :initial-value first))

(defrule spaces (* #\space) (:constant nil))
(defrule integer (+ (digit-char-p character)) (:text t) (:function parse-integer))
(defrule parens (and "(" spaces sum spaces ")") (:function third))
(defrule factor (or integer parens))

(defrule mul-op (or "*" "/") (:lambda (op) (if (string= op "*") #'* #'/)))
(defrule add-op (or "+" "-") (:lambda (op) (if (string= op "+") #'+ #'-)))

(defrule product (and factor (* (and spaces mul-op spaces factor)))
  (:destructure (first rest) (fold-left first (mapcar (lambda (x) (list (second x) (fourth x))) rest))))
(defrule sum (and product (* (and spaces add-op spaces product)))
  (:destructure (first rest) (fold-left first (mapcar (lambda (x) (list (second x) (fourth x))) rest))))
#+end_src

#+begin_src lisp
(list (parse 'sum "2 * (3 + 4) - 5")
      (parse 'sum "100 / 7"))
#+end_src

#+RESULTS:
: (9 100/7)

Errors carry the position:
#+begin_src lisp
(handler-case (parse 'sum "2 * (3 + x)")
  (esrap-parse-error (e)
    (list (esrap-error-position e) (type-of e))))
#+end_src

#+RESULTS:
: (6 ESRAP-PARSE-ERROR)

Parse part of the input, Lark's ~parse~ with a start rule:
#+begin_src lisp
(multiple-value-list (parse 'product "6 * 7 rest" :junk-allowed t))
#+end_src

#+RESULTS:
: (42 5 T)
