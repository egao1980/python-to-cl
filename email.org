The email package is a library for managing email messages.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ ~EmailMessage~: headers, text and HTML bodies, attachments, encodings
+ Parse messages, walk MIME parts
+ smtplib: SMTP, STARTTLS, implicit TLS, AUTH
+ imaplib / poplib: read mailboxes

Fixed on 2026-11-24 – 26 (mail-protocol 0.3.0 – 0.3.2, mime-protocol 0.3.2 – 0.3.4): ~Date~, ~Message-ID~, attachments, HTML alternatives, SMTP AUTH and STARTTLS, so Gmail and SES work ([[https://github.com/egao1980/mail-protocol/issues/3][mail-protocol#3]]); display-name envelopes ([[https://github.com/egao1980/mail-protocol/issues/4][#4]]); header injection ([[https://github.com/egao1980/mime-protocol/issues/12][mime-protocol#12]]) and SMTP command injection ([[https://github.com/egao1980/mail-protocol/issues/8][#8]]) refused. Since then: mail-protocol 0.3.3 refuses CR / LF in IMAP arguments ([[https://github.com/egao1980/mail-protocol/issues/9][mail-protocol#9]]), and encoding-protocol 0.3.1 knows koi8-r, Shift JIS, EUC-JP and GB2312 / GBK by their MIME names ([[https://github.com/egao1980/encoding-protocol/issues/5][encoding-protocol#5]]). Gaps: comments in display names ([[https://github.com/egao1980/mail-protocol/issues/13][#13]]) and form-data ~filename*~ ([[https://github.com/egao1980/mime-protocol/issues/21][mime-protocol#21]]); mime and mail don't pass the new charset names through yet ([[https://github.com/egao1980/mime-protocol/issues/22][mime-protocol#22]], [[https://github.com/egao1980/mail-protocol/issues/17][mail-protocol#17]]); no iso-2022-jp, Big5 or EUC-KR ([[https://github.com/egao1980/encoding-protocol/issues/7][encoding-protocol#7]]).

** Python to CL examples
:PROPERTIES:
:UNNUMBERED: t
:END:
The SMTP examples send to Mailpit in Docker: ~docker run --rm -p 127.0.0.1:11025:1025 -p 127.0.0.1:18025:8025 axllent/mailpit~.

#+begin_src python
msg = EmailMessage()
msg["From"], msg["To"], msg["Subject"] = "ann@example.com", "bob@example.com", "Report ready"
msg.set_content("The weekly report is ready.")
with smtplib.SMTP("127.0.0.1", 11025) as s:
    s.send_message(msg, to_addrs=["bob@example.com", "audit@example.com"])
#+end_src

An HTML alternative and an attachment, ~add_alternative~ / ~add_attachment~; against a real server use ~(use-smtp-backend :host "smtp.example.com" :port 587 :starttls t :username … :password …)~:
#+begin_src lisp
(let ((m (stack-mail:make-message :from "Ann Lee <ann@example.com>" :to "bob@example.com"
                                  :subject "Report attached" :body "The weekly report is attached.")))
  (stack-mail:add-alternative m "<p>The <b>weekly report</b> is attached.</p>")
  (stack-mail:add-attachment m (format nil "name,total~%Ann,3~%") :filename "report.csv")
  (stack-mail:send m)
  (let ((sum (aref (gethash "messages" (com.inuoe.jzon:parse (dex:get "http://127.0.0.1:18025/api/v1/messages"))) 0)))
    (list (gethash "Subject" sum) (gethash "Name" (gethash "From" sum)) (gethash "Attachments" sum))))
#+end_src

#+RESULTS:
: ("Report attached" "Ann Lee" 1)

CR / LF in a header value or an address is refused, not sent as another header or SMTP command:
#+begin_src lisp
(handler-case (stack-mail:make-message :from "ann@example.com" :to "bob@example.com"
                                       :subject (format nil "Hi~C~CBcc: eve@example.com" #\Return #\Newline))
  (mime-protocol:mime-header-error (e) (type-of e)))
#+end_src

#+RESULTS:
: MIME-PROTOCOL:MIME-HEADER-ERROR

*** cl-mime
Attachments, ~msg.add_attachment(...)~:
#+begin_src lisp :exports source :results silent
(asdf:load-system "cl-mime")
#+end_src

#+begin_src lisp
(let* ((body (make-instance 'cl-mime:text-mime :subtype "plain" :charset "utf-8"
                                               :content "Report attached."))
       (file (make-instance 'cl-mime:mime :type "text" :subtype "csv" :encoding :base64
                                          :disposition "attachment"
                                          :disposition-parameters '((:filename "report.csv"))
                                          :content (format nil "name,total~%Ann,3~%")))
       (text (with-output-to-string (s)
               (cl-mime:print-mime s (make-instance 'cl-mime:multipart-mime :subtype "mixed"
                                                                            :content (list body file))
                                   t t)))
       (back (cl-mime:parse-mime text)))
  (list (cl-mime:content-subtype back)
        (mapcar #'cl-mime:content-type (cl-mime:content back))
        (cl-mime:content-disposition-parameters (second (cl-mime:content back)))))
#+end_src

#+RESULTS:
: ("mixed" ("text" "text") ((:FILENAME "report.csv")))
