:PROPERTIES:
:UNNUMBERED: t
:END:
https://docs.python.org/3/library/email.html

https://docs.python.org/3/library/smtplib.html

The email package is a library for managing email messages.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ ~EmailMessage~: headers, text and HTML bodies, attachments, encodings
+ Parse messages, walk MIME parts
+ smtplib: SMTP, STARTTLS, implicit TLS, AUTH
+ imaplib / poplib: read mailboxes

| [[https://github.com/egao1980/mail-protocol][mail-protocol]] | 0.2.0   | ~make-message~ / ~parse-message~ / ~send~; Bcc kept out of the headers; IMAP client (~select~, ~search~, ~fetch~, ~idle~) over a stream you supply. Also systems ~mail-backend-smtp~ (EHLO / MAIL / RCPT / DATA) and ~mail-backend-memory~ (for tests). |
| [[https://github.com/egao1980/mime-protocol][mime-protocol]] | 0.3.0   | Media types, multipart, Content-Transfer-Encoding, Content-Disposition (RFC 2045 / 2046 / 6266); ~guess-type~. Gaps: no ~Date~ / ~Message-ID~ headers, attachments or HTML alternatives in ~make-message~; SMTP has no AUTH or STARTTLS, so no Gmail or SES ([[https://github.com/egao1980/mail-protocol/issues/3][mail-protocol#3]]). Status 2026-11-23: canonical header names shipped in mime-protocol 0.3.0; the rest is in [[https://github.com/egao1980/mail-protocol/pull/6][PR #6]], not merged: the SMTP envelope rejects a display-name address with 501 ([[https://github.com/egao1980/mail-protocol/issues/4][#4]]), CR / LF in a header value injects headers ([[https://github.com/egao1980/mime-protocol/issues/12][mime-protocol#12]]) and in an address injects SMTP commands ([[https://github.com/egao1980/mail-protocol/issues/8][#8]]).

** Python to CL examples
:PROPERTIES:
:UNNUMBERED: t
:END:
The SMTP examples send to Mailpit in Docker: ~docker run --rm -p 127.0.0.1:11025:1025 -p 127.0.0.1:18025:8025 axllent/mailpit~.

#+begin_src python
msg = EmailMessage()
msg["From"], msg["To"], msg["Subject"] = "ann@example.com", "bob@example.com", "Report ready"
msg.set_content("The weekly report is ready.")
with smtplib.SMTP("127.0.0.1", 11025) as s:
    s.send_message(msg, to_addrs=["bob@example.com", "audit@example.com"])
#+end_src

*** cl-stack
#+begin_src lisp :exports source :results silent
(asdf:load-system "mail-backend-smtp")
(asdf:load-system "mail-backend-memory")
(asdf:load-system "dexador")
(asdf:load-system "com.inuoe.jzon")

(defvar *msg* (stack-mail:make-message :from "ann@example.com" :to "bob@example.com"
                                       :bcc "audit@example.com"
                                       :subject "Report ready"
                                       :body "The weekly report is ready."))
#+end_src

The wire form; Bcc is envelope-only:
#+begin_src lisp
(stack-mail:print-message *msg*)
#+end_src

#+RESULTS:
#+begin_example
From: ann@example.com
To: bob@example.com
Subject: Report ready
MIME-Version: 1.0
Content-Type: text/plain; charset=utf-8
Content-Transfer-Encoding: 8bit

The weekly report is ready.
#+end_example

Send over SMTP:
#+begin_src lisp :results silent
(mail-backend-smtp:use-smtp-backend :host "127.0.0.1" :port 11025)
(stack-mail:send *msg*)
#+end_src

What Mailpit received:
#+begin_src lisp
(let ((m (aref (gethash "messages" (com.inuoe.jzon:parse (dex:get "http://127.0.0.1:18025/api/v1/messages"))) 0)))
  (list (gethash "Subject" m)
        (map 'list (lambda (a) (gethash "Address" a)) (gethash "To" m))
        (map 'list (lambda (a) (gethash "Address" a)) (gethash "Bcc" m))))
#+end_src

#+RESULTS:
: ("Report ready" ("bob@example.com") ("audit@example.com"))

In tests, the memory backend records instead of sending:
#+begin_src lisp
(let ((stack-mail:*mail-backend* (mail-backend-memory:make-memory-backend)))
  (stack-mail:send *msg*)

#+end_src

#+RESULTS:

*** cl-mime
Attachments, ~msg.add_attachment(...)~:
#+begin_src lisp :exports source :results silent
(asdf:load-system "cl-mime")
#+end_src

#+begin_src lisp
(let* ((body (make-instance 'cl-mime:text-mime :subtype "plain" :charset "utf-8"
                                               :content "Report attached."))
       (file (make-instance 'cl-mime:mime :type "text" :subtype "csv" :encoding :base64
                                          :disposition "attachment"
                                          :disposition-parameters '((:filename "report.csv"))
                                          :content (format nil "name,total~%Ann,3~%")))
       (text (with-output-to-string (s)
               (cl-mime:print-mime s (make-instance 'cl-mime:multipart-mime :subtype "mixed"
                                                                            :content (list body file))
                                   t t)))
       (back (cl-mime:parse-mime text)))
  (list (cl-mime:content-subtype back)
        (mapcar #'cl-mime:content-type (cl-mime:content back))
        (cl-mime:content-disposition-parameters (second (cl-mime:content back)))))
#+end_src

#+RESULTS:
: ("mixed" ("text" "text") ((:FILENAME "report.csv")))
