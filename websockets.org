* websockets
:PROPERTIES:
:UNNUMBERED: t
:END:
https://websockets.readthedocs.io/en/stable/

websockets is a library for building WebSocket servers and clients in Python with a focus on correctness, simplicity, robustness, and performance.

** Features
:PROPERTIES:
:UNNUMBERED: t
:END:
+ Client ~connect~ and server ~serve~ on asyncio; a threaded ~sync~ API
+ Text and binary messages, ping / pong, close codes
+ permessage-deflate compression
+ TLS, subprotocols, extra headers, routing

** Python to CL examples
:PROPERTIES:
:UNNUMBERED: t
:END:
#+begin_src python
async def shout(ws):
    async for msg in ws:
        await ws.send(msg.upper())

async with websockets.serve(shout, "127.0.0.1", 18765):
    async with websockets.connect("ws://127.0.0.1:18765/echo") as ws:
        await ws.send("hello")
        await ws.recv()
#+end_src

Server:
#+begin_src lisp :results silent
(defvar *server*
  (ws:make-server :backend *backend* :host "127.0.0.1" :port 18765 :path "/echo"
                  :transport :http/1.1
                  :on-connect (lambda (conn)
                                (ws:on conn :message
                                       (lambda (m) (ws:send conn (string-upcase m)))))))
(ws-protocol:start-ws-server *server* :background t)
#+end_src

Client:
#+begin_src lisp
(let ((got '()))
  (ws:with-connection (c "ws://127.0.0.1:18765/echo" :backend *backend* :transport :http/1.1)
    (ws:on c :message (lambda (m) (push m got)))
    (ws:send c "hello")
    (ws:send c "world")
    (loop repeat 50 until (= (length got) 2) do (sleep 0.05)))
  (reverse got))
#+end_src

#+RESULTS:
: ("HELLO" "WORLD")

*** websocket-driver
The same server, with the driver's own client:
#+begin_src lisp
(let ((client (wsd:make-client "ws://127.0.0.1:18765/echo"))
      (got nil))
  (wsd:on :message client (lambda (m) (setf got m)))
  (wsd:start-connection client)
  (wsd:send client "driver")
  (loop repeat 50 until got do (sleep 0.05))
  (wsd:close-connection client)
  got)
#+end_src

#+RESULTS:
: DRIVER
